# 2025 MCM C：CoEvo 首个综合长期工作任务候选

**状态（2026-10-15）：官方题面及五份 CSV 已下载并核验，保守历史回测数据视图已生成；尚未启动 W0 执行、训练或成果评价。** 本目录属于任务设计和未来实验记录，不等于赛事官方参赛作品。研究主线见[研究方案](../../docs/研究方案.md)，评价依据见[评估与统计](../../docs/评估与统计.md)。

## 任务来源和研究用途

官方 [2025 MCM Problem C — Models for Olympic Medal Tables](https://www.contest.comap.org/undergraduate/contests/mcm/contests/2025/problems/2025_MCM_Problem_C.pdf) 及其随题发布的数据包。原题任务涵盖各国金牌/总奖牌预测及区间、2028 洛杉矶奥运预测、未来首次获奖牌国家数量及概率、赛事项目规模/类型的关联、著名教练影响、三个国家的教练投入建议和至少一项原创推断；最终要求 PDF 论文（含摘要）。应完整保留官方语义及允许使用的资料范围，研究助手不得替模型预先规定具体预测算法。

官方题面声明只能使用随题附件的数据进行建模与数据分析；允许外部资源用于背景与解释，须注明来源。数据文件为：
- `summerOly_medal_counts.csv`：1896–2024 各届奖牌榜；
- `summerOly_hosts.csv`：历史及部分未来主办国；
- `summerOly_programs.csv`：项目/小项安排及数量；
- `summerOly_athletes.csv`：运动员、国家/队伍、项目/小项、年份和奖牌；
- `data_dictionary.csv`：数据字段解释。

实际文件名、列名、行数、编码、原始字节哈希及官方 URL 见[数据清单](data-manifest.json)。完整原件仅保存在忽略的本地数据目录。比赛提供的 2024 排名及金牌数已公开，原题/解答可能出现在预训练中，因此**这是一条长时工作流，不是独立盲测 H**。

## 交付目标：完整工作而非微题合集

Agent 在独立任务工作区获得官方题面、授权的数据快照、已有工具和明确时间/调用预算。它自己组织连续工作：理解赛题→检查数据→提出假设及基线→实现模型和历史外推回测→生成预测与不确定性分析→进行项目结构/教练效应论证→检查错误并完成报告。以上是能力维度，不是预设固定流水线；它可以修订方案、失败恢复、改变代码。只有实际收到的外部反馈才记录为用户/研究者反馈。

最终工件应包含能从初始输入复现的代码、运行方法、主要清洗与特征定义、滚动预测结果及指标、2028 预测表和区间、无历史奖牌国家分析、项目/东道主因素论证、教练影响的可识别性与建议、必要图表、面向赛题受众的论文式报告。不能因无法证明教练因果效应而强行捏造数字；可以陈述数据局限，若使用情景分析需标明假设。

## 时间外推：防止未来信息进入过去

建议建立不止一个历史预测时点，如目标 2016、2020、2024：各时点只允许访问**预测决策时点已知**的信息。基础历史数据至少应屏蔽当年及之后的奖牌、运动员结果、赛后修订特征；主办地、项目数量及队伍名变动须判断在该时点是否真实公开，缺发布时点记录则采取保守屏蔽。2020 赛事延期，需要区分奥运届次、实际举办日与预测日期。

验证从数据快照开始，而不只是模型内部设置 `year<T`。Agent 工作区不能出现隐藏的预测目标答案或未来资料；独立检查器持有真值。官方包含未来主办和赛程相关列，使用它们需要记录当时已知与未知，而不是偷偷将它们全部作为历史训练特征。建议同时提供不含未来协变量的强基线，避免把未来信息优势错判成模型智能。

预测误差可以评价历史外推年份；**2028 年尚无实际奖牌结果**，只能检查预测表、区间方法和情景一致性，不能给出 2028 MAE/覆盖率。历史赛题已公开，不能用同一道题的时间切片生成统计意义上的独立科研来源；未来需其他新题/真实工作流确认迁移。

## 可核验的成果与失败

结果检查分三层：
1. **机器可核验**：可运行、文件数据一致、国家映射、时间数据可见性、金牌与总奖牌非负及逻辑约束、全部国家覆盖、回测预测表、脚本能重新生成图表/表格、正确退出码。
2. **定量建模质量**：与不使用未来信息的朴素基线比较金牌/奖牌计数误差；区间覆盖和宽度或适用 proper scoring；首获奖牌概率校准、国家子群体误差、随时间漂移；各指标有明确分母，不允许用模糊论文质量分代替。
3. **科研判断与工作行为**：假设-代码-结论一致，相关性/因果边界，理解题面、异常数据处理、失效信息撤回、适时询问、工具错误恢复、诚实停止、独立首次成功与反馈后成功分开。人工科研评审尽可能盲化模型身份；模型自我打分只作诊断。

部分有效工件即使最后没有完成 PDF 也可评分；不能对“我已完成”的表述给成功分。记录 token/工具调用/墙钟/GPU/人工反馈消耗。超时、环境故障与真实方法缺陷分别归类。

## 与 CoEvo 学习机制的关系

- **首次 W0 执行**：观察模型独立工作能力、失败与有效成果；提供实际背景/任务权限，但不给它事先准备的参考答案。
- **反馈续接**：给予检查器实际观察到的错误、结果及必要用户纠正；观察同会话纠正。反馈不自动意味着合法正向训练。
- **新任务上的 Q1**：固定模型，比较无历史、真实完整历史、可检索记录、提炼后的经验；特别设计预测时点更改、数据字段变更、历史规则撤回等具有可核验结果的后续工作；这些仍属此赛题来源簇。
- **未来 Q2**：仅将已经证实的正确行动、修复过程等合法 L 来源用来训练，在与学习来源隔离的新任务上评估 W1，同时检查不相关旧能力。不得把先前作为 D/G 检查的结果重新标为合法 L。
- **未来 Q3**：必须引入另外独立任务流，不从本题的十个扰动副本中虚构多个“独立流”。

## 执行前仍须明确的事实

官方附件的准确取得方式、字节哈希、数据字典与时间可见性必须基于下载内容核实。任务预算应根据一次真实无学习执行与资源测量确定，报告完整配额，而不是机械预设一个过短的工具调用数。对两个 4B 模型比较时应保持同样的任务成果要求和可比资源，允许正确原生工具/思考设置。

本项目已取得官方数据并准备回测输入；**没有开启 Agent、没有进行模型训练、没有产生 MCM 预测值、没有宣布完成此题。**

## 数据准备实测（2026-10-15）

通过官方目录取得 PDF（5,119,355 字节）和 ZIP（3,145,600 字节），ZIP CRC 校验通过，两次独立取回的字节哈希一致。五份 CSV 原件不改写：运动员252,565行、奖牌1,435行、主办地35行、项目74行、字典50行（各自第一行为标题，不将字典视为统一字段表）。字典和项目表采用CP1252解码，其余UTF-8-SIG。项目表的年份列止于2024，未来年份实际出现在主办地表；不预先假定官方包含2028项目安排。

共享实现 `coevo.mcm_data` 从官方原件准备两类输入：`full-task/` 保留完整PDF与五份CSV，供2028综合建模；`retrospective/<T>/input/` 只给目标届次之前的奖牌、运动员与历史主办记录。后者不含PDF、字典或项目表，避免题面已知答案、字典示例及未证实发布时间的协变量进入回测。目标届次的奖牌真值单独保存在 `evaluation-only/`，未来执行时不挂载到模型工作区；目录分开本身不等于执行沙箱。

生成2016/2020/2024三个视图，逐文件检查所有可见记录均满足Year<T。它们是保守的回顾性开发视图，**不是完整历史信息重建**：官方数据没有版本发布时间，现代国名、运动员元数据或赛后修订仍可能存在。2020届实际举办于2021，记录中明确分开。奖牌表只覆盖获牌队伍，全参与/零奖牌国家的评价分母及队伍映射尚需定义，不将真值表行数直接当作国家覆盖分母。

本地原件：`data/mcm-2025-c/official/`；当前准备产物：`data/mcm-2025-c/prepared-v2/`（链接到冷盘，均不入Git；v1保留，v2补记年份范围和下载完成时间，过滤策略不变）。重新准备须指定新的输出目录：

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.mcm_data \
  --official "$COEVO_MCM_OFFICIAL" --out "$COEVO_MCM_PREPARED"
```

本批两项编码/时间过滤单元检查，以及真实ZIP CRC、全部回测输入年份与重复下载哈希核验通过。没有选择预测算法或替模型写解答。下一步是建立现有Pi执行环境中的完整任务入口和实际资源预算，再运行W0；训练或Spark替换不随数据准备自动启动。全部当前派生资料属于同一公开赛题D来源簇，既不标H，也不自动准入L。

## 首次完整 W0 执行入口

用户已要求启动自主建模。复用 `coevo.mcm_run` → 现有 Pi SDK 的 read/write/bash，不新建执行框架。使用 `configs/mcm-2025-c.json`：Qwen3.5-4B BF16 W0、原生上下文容量139264、thinking关闭、temperature0/seed17、原生会话不压缩；45分钟Agent墙钟、160次工具调用、每次输出最多8192token、单次bash最多120秒。服务初始化另有现有15分钟上限，不计入Agent工作时间；启动和总耗时分别记录。预算是首次有界开发配额，不是正式研究最优预算。

任务环境独立于训练环境：`requirements.in` 列科学计算库，`requirements.txt` 记录本次解析版本和包哈希。只读绑定官方数据/题面，其余工作区允许正常编辑；离线执行，不挂载CoEvo源码、私人资料或评价区。给完整题面、完整数据和交付要求，模型自主选择数学与编程方法，不提供参考算法或解答。机器可读2028预测表的列约定仅用于成果读取，不要求学习建议或推理过程采用固定schema。

```bash
uv venv --python /usr/bin/python3 "$COEVO_MCM_ENV"
uv pip sync --python "$COEVO_MCM_ENV/bin/python" --require-hashes experiments/mcm-2025-c/requirements.txt
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.mcm_run \
  --prepared "$COEVO_MCM_PREPARED" --environment "$COEVO_MCM_ENV" \
  --config configs/mcm-2025-c.json --out "$COEVO_MCM_RUN" --pi-entry "$COEVO_PI_ENTRY"
```

输出目录必须为新目录。初始官方输入哈希、环境/锁、配置/源码哈希、Git提交、Pi版本入口哈希、模型请求、工具轨迹、原生会话、GPU五秒采样及所有工作工件留在本地运行目录。任务结束后关闭本次服务；不因观察等待超时重启任务。不训练或晋升。

自动检查只覆盖输入未修改、工件清单和预测表基本数值约束；不把正常退出、PDF存在、工具运行或模型自报完成视为整题成功。国家覆盖、时间过滤实现、区间方法和建模质量须结合模型实际代码/工件核查。全量工作区已经含历史成绩，不能将本次内生回测包装成隐藏真值预测；保守视图用于后续真正隔离执行。
