预算拒绝发生在工具操作前；尝试数包含被拒绝的最后一次，不能写作执行了 25/13 次授权动作。模型多次测试命令用管道截断输出，可能掩盖退出码；独立检查直接调用测试命令，保留真实退出码。反馈续接的失败测试遗漏实际输入文件或 stdin 内容，产生空输出，不能据此把可用实现判成编码功能错误。失败测试没有被研究助手修好，仍保留供分析。

这三次属于同一 D 来源簇，第二次改变了接入与验收版本，第三次增加了反馈和预算，不是独立三任务、经验学习收益或参数收益。此前 131072-token 资格不因此次输入累计 token 较多而重复成立；累计请求 token 与单次实际上下文长度分别理解。资源、结果和产物引用见 [measured_results.json](measured_results.json)。总运行时长包含服务加载和外部检查；本轮推理服务已停止。

## 执行、检查与数据边界

自有薄适配位于 `scripts/pi-project-agent.mjs`，复用已有 Pi SDK，不引入第二套 Agent。文件工具限定独立副本，拒绝目录逃逸与符号链接；bash 使用 bubblewrap，隔离网络及宿主项目，只挂载任务副本、只读 Python 环境及必要系统运行库。受控终端、路径映射、工具预算和会话 fork 已实际运行，不代表上游完整 CLI 或全部扩展验收。

`coevo.project` 准备可复位副本、记录任务与源码哈希、执行学生、独立评价。评价使用冻结上游测试和外部 CLI 检查；学生不能通过修改可见测试替代这些检查。新测试单独执行并保留失败。首轮检查器只核验功能及旧回归，v2 在复测前补齐“提交测试”要求；未追溯重判首轮。首轮保存哈希但没有完整源码副本，后两轮保存实际源码、配置、锁文件和适配脚本快照；首轮不宣称达到完整重建要求。

三个任务都标 `split=D`、`train_authorized=false`。导出保留研究者提示、学生原始输出、工具调用和返回、失败、外部反馈、会话续接边界及来源簇；续接标为 `feedback_assisted=true`，没有被记成真实用户纠错或强教师示范。当前导出 3 条交互、0 个训练候选，未记录不可见思考。原始记录和任务副本归档在 `/mnt/e/CoEvo/artifacts/project-tasks/`，数据导出位于 `/mnt/e/CoEvo/data/exports/`；代码中的本地路径可复核，不代表云端具有相同环境。

## LoRA 初步诊断

`coevo.diagnose` 只读取旧合成 L 候选、历史轨迹和本地 tokenizer，未加载模型做推理或训练。六条样本的模板前缀均对齐，监督总计 327 token，目标全部为 write，没有 read、恢复或正常停止目标；退化轨迹包含重复工具、无效工具和无法停止。结果见 [lora_diagnosis.json](lora_diagnosis.json)。

这降低了“当前六样本发生明显前缀错位”的解释可信度，支持优先诊断监督覆盖，但尚未定位 LoRA 退化原因。优化设置、模块覆盖、推理 Adapter 加载和完整轨迹配方的受控比较仍未执行。Marko 的 D 任务不能因发现学习价值而改划为 L 或用于微调。
