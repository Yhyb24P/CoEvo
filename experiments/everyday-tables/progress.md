# 日常表格行为基线：2026-10-14 开发记录

本批按用户选择的“表格清理与核对”推进；这是研究者构造、无私人信息的有界开发任务，不是真实用户纠错流或正式确认实验。用户随后授权导出多个 Codex 工作区的可见交互，包括软件开发、科研分析、文档和表格工作；表格不构成长期任务范围的上限。

## 实现与数据

`src/coevo/everyday.py` 提供列名/金额归一、双表核对、筛选汇总三种 L 程序族，以及缺汇率、只读权限两种 D 边界任务。复用单一 Pi 执行链和真实会话 fork；原始输入只读，直接 write 和 bash 均只能修改声明的输出。模型看到统一 `/workspace`，避免真实宿主路径与工具沙箱路径冲突。独立检查器比较 CSV 单元格、原始文件状态、进程和正常停止；边界回答仅作初步短语检查，不代表正式 BDA/FCR。

`behavior.py` 为真实轨迹中的正确读取、执行、写入和停止生成目标级证据；工具观察与失败动作保留为上下文，不作为正向监督。未完成的 L 任务可以保留独立核验过的读取，但不能监督虚假完成。反馈续接只准入反馈之后的新目标；D 不进入训练。工具执行前后状态记录支持逐步核验。训练器保留旧格式，并加入前缀、工具 schema、证据哈希、重复候选、token/步数/时间预算检查。
