# 多工作区 Codex 教师来源：2026-10-14

用户授权尝试导出 Codex 自身的真实交互、任务与工具调用用于训练，继而明确覆盖其他工作区，并要求不因软件开发、科研分析等任务类型预先排除数据。本次实现本地可见轨迹导出及原生终端调用的 Pi 格式适配提议；尚未完成教师目标准入或使用这批数据训练。

## 实际导出

扫描本机会话 JSONL 的首条元数据，再导出授权范围内的可见 `response_item`。155 个日志快照对应 133 个唯一会话 ID、84 个工作区；75 个快照来自持久工作区，80 个来自临时或 probe 工作区。共保留 4,747 条消息、23,725 个调用、23,728 个返回记录。计数包含历史快照和可能重复，不等于独立任务量。

原始输出在 `/mnt/e/CoEvo/data/codex-teacher/20261014-visible-v2/`：

- 每个日志有独立导出文件，记录可见角色、时间、调用 ID、源行号和内容哈希。
- `manifest.json` 记录原日志路径、固定前缀字节数/哈希、工作区、来源隔离组、导出哈希、重复及未配对记录。
- `shell-proposals.jsonl` 与 `adaptation-audit.json` 保存 2,390 个去重的待核验终端目标提议及未适配原因。

系统/开发者消息、隐藏推理、事件重放、压缩摘要和注入环境规则不复制；疑似凭据及嵌入特权日志的记录整条排除。过滤为初步规则，不声称完全匿名。可见消息与教师工具动作保留真实来源，不标为小模型输出。原始数据和提议均位于忽略的本地目录，不提交或公开。

首次导出发现同会话 ID 的不同日志会覆盖文件，现改为会话 ID 加源路径的独立日志标识，并补回归；v1 留有失效标记，v2 为本次有效导出。存在 143 组跨日志重复记录，以及 17 个未配对调用、20 个未配对返回；缺失返回不会解释为成功。活跃会话仅取扫描时已存在的固定字节前缀，不循环追踪追加内容。

## 适配与训练边界

只对具备可见任务、配对返回、明确正常结束的原生 `exec_command` 构造 Pi `bash` 形状的提议；宿主工作路径到 `/workspace` 的替换仅是待验证的映射，不执行历史命令。其余 21,162 个调用需要独立工具适配，167 个原生终端调用没有确认正常成功结束，6 个没有配对结果。JavaScript 编排不解析执行；多 Agent 调度、浏览器及文件补丁接口保留原始记录，不直接冒充学生工具。

所有源和提议为 `split=unassigned`、`train_ready=false`，现有学生证据准入不接受它们。正常进程退出只支持调用完成，不能证明任务正确。CoEvo 会话已经含开发/回归反馈；其他会话的历史评价曝光也未核查，因此不能将整个导出标为 L 或宣称完全无 H 信息。项目及子工作区采用保守的统一隔离组，未解的临时工作区暂同组；来源派生、复制和摘要还须随具体任务确认，不能按消息随机划分。

实际下一步是按来源挑选可重建输入和客观结果的任务片段，重建授权和完整上下文，适配当前工具环境，再独立核验输出后形成教师训练候选。随后在 4B 模型上比较通用行为与领域能力的迁移，记录上下文长度、监督 token 和旧能力；不将教师原任务完成率算作学生能力，也不以样本数量声称收益。
