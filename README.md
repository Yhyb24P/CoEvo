# CoEvo · Agent—模型持续适应研究

研究小模型 Agent 是否能够通过**真实完整工作、反馈、外部经验、Harness 改进与参数学习**，在可比较资源条件下持续获得有用且可迁移的能力提升，并进一步学会改进自身的工作方式。研究重点是真实任务成果与长期行为变化，不是不断增加任务拆分、检查器或软件流程。

**现状（2026-10-15）**：使用单 main 分支，项目正常推进。已接受研究底座为 Qwen3.5-4B 原始 W0；Spark-X2.5-4B 是尚未实测的候选，暂无已晋升的参数更新版本。Pi 原生工具、会话续接、Qwen thinking 与 BF16 LoRA 的技术路径已经实测可用；这不等于研究的协同进化目标已经成立。

[2025 MCM C](experiments/mcm-2025-c/README.md) 是第一个高复杂度综合开发案例：首次无工件，后续 thinking 恢复保存源码，但预测阶段独立执行失败，并存在模型统计方法缺陷，故不是有效完成。既有局部训练候选在开发任务上出现 6/16→8/16 的窄范围改善；部分完整经历对照 11/12 高于自由笔记 7/12，但尚无独立来源的持续迁移或训练后协同进化确认。完整记录见[阶段事实](experiments/real-work-foundation/stage-update-2026-10-14.md)和[thinking 恢复摘要](experiments/mcm-2025-c/thinking-recovery-results.json)。

**当前研究方向**：重新判断 Qwen/Spark 在代表性完整任务上的实际能力与成本；让软件工程、科学分析和持续工作共同提供有价值的真实经历；研究哪些有效部分成果、反馈修正与经验值得保留或进入权重；在未来任务中区分外部指导、Agent 自主改进和学习型自我改进。参数学习不必等整题成功，Harness 演化也不预设必须新增复杂编排或搜索平台。
