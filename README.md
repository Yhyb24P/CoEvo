# CoEvo · AGENT-MODEL-RSI

**面向普通人日常工作的轻量级持续学习 Agent 研究。** 固定使用 Qwen3.5-4B，研究在长期、真实、重复的个人工作中，如何从交互中形成可验证经验、正确管理指令，并选择性更新模型。研究场景具有实际价值；参数学习及递归自改进是否带来可归因的收益仍待实验确认。

项目不内置高级 Agent、复杂多 Agent 团队或底座竞赛。复杂科研和大型软件工程由用户在其他平台处理。本地模型应执行能够完成且获得授权的工作，缺信息时询问，无法完成时明确说明，不虚构操作结果，也不以一律拒绝代替行动。

## 三个科学问题

- **Q1：经验归属。** 交互应该忽略、保留为实例、形成带条件的技能，还是进入参数学习候选？如何处理过时要求及撤回？
- **Q2：参数增量。** 外部经验（R）和 LoRA 参数更新（W）在未见日常任务上分别贡献多少？是否遗忘旧技能、产生误拒绝或错误完成宣称？
- **Q3：双向反馈。** 更新后的模型能否在相同候选池和资源预算下改善下一周期的经验提炼与训练候选选择，而不是仅因更多历史和计算得益？

K=指令生命周期，R=外部经验，W=模型参数，S=训练候选选择；这些是研究因素，不必开发为四个服务。

## 实施方法

复用既有 Pi SDK/momo-code、vLLM、Transformers/PEFT。以文件整理、文档修改、表格清理、信息提取、本地清单和有限工具操作为主要任务环境；不把合成 JSON 求和作为正式能力证据。持久化或训练私人交互必须单独获得授权。采用经核验的完整 Assistant 行为监督，并参考 [SRFT](https://openbmb.cn/en/blog/self-replay-fine-tuning) 自生成通用能力 replay。原论文 Task:Replay=4:1 是样本数量比例；其遗忘下降数字不能直接外推到本项目。

## 实际状态（2026-10-13）

[工作站研究快照](experiments/workstation-rsi/review_snapshot.md)记录：原始 Qwen3.5-4B 在 RTX 5090 D 上完成一次 **131072 输入 token** 的定位与工具资格试跑；一次真实 BF16 LoRA 训练共 **6 条合成任务、327 个监督 token、6 步**，候选独立加载后旧任务从 **3/3 降至 0/3**，未晋升。已有交互提取、工具核验、版本记录和真实参数更新，但**没有完成真实日常长期交互、多周期 RSI、正式 Q1–Q3 评价或笔记本部署**。当前实验已暂停；文档修改不授权恢复训练。详见[机器可读结果](experiments/workstation-rsi/measured_results.json)。
