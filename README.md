# CoEvo · Agent—模型持续适应研究

个人科研项目。当前以 **Qwen3.5-4B（W0）** 为已接受研究底座；**Spark-X2.5-4B** 为待公平实测的候选，研究小模型 Agent 在真实、长期交互中如何利用执行经历、用户反馈、外部经验及参数更新获得可迁移能力，并控制错误沿用和遗忘。软件开发、科研分析、文件与日常工作均可作为合法任务来源；任务价值由真实结果而不是场景名称决定。

**当前状态：正常研究与开发，采用单 main 分支的个人科研模式。** 直接在 main 开发、提交和同步 GitHub，保留提交后自动 CI，不默认建立开发分支或 PR。研究进展由 Git 提交记录，重要阶段可用 Tag 固定版本。此前阶段性暂停是历史运行状态，不代表项目终止或归档；推理、训练及 RSI 周期由具体研究需求和用户指令决定。当前接受模型仍为 W0，训练候选未晋升。

研究主线已调整为**真实完整工作经历驱动的长期能力变化**；[2025 MCM C 奥运奖牌建模](experiments/mcm-2025-c/README.md) 确立为首个综合性长期工作任务候选，已完成官方数据准备及首次W0自主执行；首轮停滞于数据摘要，未产生建模工件。

已完成原生 Pi 执行、纠错与经验提议、真实 BF16 LoRA 更新，以及监督覆盖、同池选样、原生历史/笔记、反馈修订等开发对照。已有训练参数变化带来的局部任务收益证据，但尚无独立 H、正式 R×W、多流长期自适应或跨程序结构稳定增益的确认结果。主要开发记录：[2026-10-14 阶段总结](experiments/real-work-foundation/stage-update-2026-10-14.md)；[工作站试跑](experiments/workstation-rsi/review_snapshot.md)。私人会话、工作空间与模型权重不在公开仓库中。
