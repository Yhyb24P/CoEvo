# CoEvo 研究方案：真实工作驱动的 Agent—模型持续适应

**现行状态（2026-10-15）**：研究正常推进，个人工作流只使用 main。已接受的任务模型仍为 Qwen3.5-4B 原始权重 W0；Spark-X2.5-4B 尚未在 CoEvo 实测，未发生底座迁移或学习权重晋升。Qwen 原生 thinking 与 Pi 的 read/write/bash 多轮工具链路已真实验证。2025 MCM C 的 thinking 恢复尝试保存源码，但独立预测执行失败，未完成建模交付。详细事实见[任务记录](../experiments/mcm-2025-c/README.md)与[原始开发汇总](../experiments/real-work-foundation/stage-update-2026-10-14.md)；最新新增记录为[thinking 恢复结果](../experiments/mcm-2025-c/thinking-recovery-results.json)。

## 科学问题与研究对象

**中心问题**：在可比较的资源、任务机会和权限条件下，小型模型驱动的 Agent 能否通过真实长期工作、反馈、经验复用、Harness 修改和参数学习，在后续不同任务中获得可持续、可迁移的实际能力净收益，并逐步更善于改进自己的工作方式？

研究对象是**完整工作经历及其跨时间的行为变化**，不是工具动作成功率、训练作业数量或执行器测试覆盖率。一次工作经历包括任务需求、当时生效的指令、实际输入与工作区、行动与工具观察、用户/研究者反馈、部分与最终成果、失败、资源消耗及后续使用情况。Agent 应自主决定方法、执行、纠错和交付；外部介入允许存在，但其来源必须能与模型自身贡献区分。

研究中的变量是解释能力来源的维度，而非需要分别部署的六个子系统：K 表示指令的适用范围、时效和撤回；R 表示外部经历与可复用经验；𝓗 表示提示、工具、上下文、反馈和执行循环组成的 Harness；W_task 表示任务执行模型权重；W_evolver 表示提出/反思改进的模型权重；S 表示训练目标和修改候选的选择策略。评价集合 H 与 Harness 𝓗 不能混淆。

- **Q1：何种经历真正帮助后续工作？** 比较无历史、可回看原始经历、提炼经验与有条件的经验应用。检验条件变化、指令撤回、过期经验误用和新任务迁移；允许结论是完整经历优于摘要，或根本无需额外记忆。
- **Q2：哪些真实行为值得进入模型参数？** 从经过事实验证的完整或部分工作、纠正经历中提取合法学习目标，考察 W0→W1 后的新增能力、遗忘与资源代价。外部 R 与参数 W 的贡献应在有解释力的任务条件下分别观察；不把训练成功或当前任务经反馈完成等同于新会话中的权重收益。
- **Q3：系统能否学会更有效地改进自身？** 先区分研究者直接改进、Agent 自主提出并实施有效 Harness 修改，以及利用过去改进结果训练后在未来更善于发现和实施改进。后两者不是同一结论；W_task 和 W_evolver 可以由同一底座在不同角色中承担，但其参数、训练来源和效果要分别识别。

**可证伪的结果**包括：经验迁移失败或造成条件误用；训练只提高同族题目且退化其他能力；更强底座不需要复杂记忆；Harness 搜索无法跨任务复用；更新后的进化器并不优于未更新的策略。遇到此类结果应收缩或替换假设，而不是添加更多审查层来制造正结果。

## 从既有实证得到的判断

此前真实 BF16 LoRA 训练、独立回载、原生 Pi 会话、反馈续接及工具执行已成立，但它们主要证明研究工具可用。四族开发任务中，W0 为 6/16，一些学习候选为 8/16；收益集中于哈希族，CSV、条件筛选没有得到一致改善。训练数据覆盖或 Replay 增加并未稳定提高效果；三种候选选择策略的未来表现均为 8/16，未见选择器优势。一组经验表示对照中，无历史 7/12、原生/完整经历 11/12、自由笔记 7/12；另一组仅自审笔记达到 11/12，但不是跨来源确认。这些均为开发证据，不是长期协同进化结论。

MCM 首次 W0 执行 71 次工具调用未留下成果；原生纠错续接仍未保存源码；在已验证 thinking 与不同采样/输出配置下，49.4 分钟、90 次工具调用产生 12,441 字节源码，独立执行却在 2028 预测阶段失败。已确认存在当期 Gold 标签泄漏、随机切分用于时间预测、错误标记的 R²、首获牌仅正类等问题。这里出现了**局部执行恢复与科学有效性之间的断层**，不能用代码存在或报告表面得分代替真实研究能力；不同推理配置同时变化，也不能归因于 thinking 的独立收益。MCM 的结果属于已曝光开发来源簇，不是独立 H。

以上事实意味着：近期更值得投入的是**底座完成实际工作的能力、来自真实结果的学习信号，以及跨任务的长期变化**。继续细分同类格式错误或为每个失败追加专用检查机制，研究收益不足。

## 真实任务生态与自然学习循环

选择具有实际成果、允许自主方法选择的任务流，而不是先构建大量静态微题。研究应逐步覆盖不同知识结构：真实软件开发与科研软件修改、科学数据分析与建模、跨会话需求变化的持续工作。任务可以长短不同，但需拥有明确需求、可检查的实际产物、现实的资源限制和独立于 Agent 自述的结果依据。CoEvo 仓库自身的开发是研究者维护系统的工作，除非专门定义和隔离，不自动视为被研究 Agent 的独立任务。

[2025 MCM Problem C](../experiments/mcm-2025-c/README.md) 保留为高复杂度综合案例。它提供数据处理、预测、解释、代码和论文交付的真实挑战，却不能独占研究来源；同题回测、提示变化及其分叉不能伪装成新的独立任务。对科学数据分析，不能只审查程序是否退出，还需核对研究结论所依赖的数据时间界限、模型假设与实际计算。允许诚实的局部成果与负结果，不通过外部代写补齐成绩。

自然学习循环是：**工作与反馈 → 辨认可复用的有效行为/失败条件 → 选择外部经验、Harness 调整或参数更新 → 在后续真实工作中观察结果 → 更新下一轮选择**。不要求每一轮同时使用所有机制，也不预设每次迭代必有收益。原始工作经历可保留为证据；经验摘要是一种候选表达，不因写入存储就获得权威。经历与训练数据的保存、复用和使用权限分开管理。

高能力参考 Agent 或研究者可以提供任务可行性参考、有效纠错或监督候选，但不得把这些外部贡献算作小模型自主完成。研究应当允许有指导的学习，再评价它能否在新会话和不同来源任务中摆脱同类指导。

## 近期推进与关键决策

**首先确定有意义的任务能力基线。** Qwen3.5-4B W0 保留为已实现的对照；Spark-X2.5-4B 是尚待实测的候选。应使用代表性的完整工作比较双方的实际交付、科学/工程正确性、纠错与实际计算成本，使用各自正确的模板、工具解析和推荐推理设置，记录而非掩盖配置差异。可有一个更强的参考执行者，用于判断任务本身的可行解与反馈质量。模型卡的公开榜单只是选型线索，不能代替 CoEvo 的实际运行。比较后选择适合单卡训练和长期追踪的主底座，不因历史投资而保留弱方案，也不因单次 MCM 失败立刻判定 Qwen 不可用。

**随后围绕不同来源的完整经历研究 Q1 和 Q2。** 优先让 Agent 真正完成或推进有价值的工作，保留有效的部分成果与失败修订。不应要求整题成功后才能研究学习；只要可确认哪些行为正确、修改为何有效，就可形成有来源、有辅助标记的经验与训练候选。把无效结论、泄漏代码或外部教师完成的工作直接作为“自主正确轨迹”属于标签污染。真实 BF16 LoRA 已可用，参数研究可以与外部经验研究按证据条件并行，不必被无关工程资格测试长期推迟。

**最后研究可持续的自我改进策略 Q3。** 从真实工作中的改进机会产生 Harness 修改或经验选择，而非为演示范式先搭建树搜索、双角色训练和统一编排平台。先观察 Agent 是否自主提出、实现并保留对未来任务有用的工作方法；有足够的有效修改经历后，再判断是否值得学习 W_evolver 及是否优于冻结策略。并行观察 W_task 更新是否改变经验利用或修改能力，避免把两类参数收益混同。

这是研究依赖和科学优先级，**不是强制阶段关卡**。真实工作发现的新证据可以改变底座、学习方法乃至任务生态；同类失败反复出现却不能产生新认识时应停止无效消耗。

## 文献依据与明确边界

- [RSIGym（arXiv:2610.10310v1）](https://arxiv.org/html/2610.10310v1) 将训练、推理、评价等研究服务与 Agent 工作区分离。其 Qwen3.8-27B 自改进案例在六个开发任务由 0.5816 提至 0.7500，但选中系统在完整 37 项 SkillsBench 上为 0.5626、初始系统 0.5666。该研究的最终评价任务在开发期间可见，作者明确不称为 held-out；这里说明局部选优不必然获得整体净收益，不证明自改进普遍无效。固定执行模型、由较强研究 Agent 修改已有 Harness 的案例将 Terminal-Bench 得分 0.3034 提至 0.4082；其资源和模型能力条件不能直接移植到本项目。
- [Evo²（arXiv:2610.13025v1）](https://arxiv.org/html/2610.13025v1) 区分任务执行器与 Proposer/Reflector 进化策略，给出了 Harness 跨编码基准迁移及训练进化器的证据。表 5 的 Polyglot 61.8→78.0，与 SWE-bench Verified 46.0→51.0（p=0.086）证据强度不同。这是探索进化策略学习的依据，不要求现在复制 EvoTIDE 的 SFT/GRPO、树搜索与 crossover。
- [Spark-X2.5-4B 官方模型卡](https://huggingface.co/XHToken/Spark-X2.5-4B) 报告多项工具和编码基准优势，但其中若干 Qwen 数字转引其他公开报告，协议并不保证严格一致，且 Spark 的服务与训练适配仍须实际核验。
- [Looped Prediction Transformer 共享记忆（arXiv:2610.02383v1）](https://arxiv.org/html/2610.02383v1) 研究模型内部递归 KV 共享；它与 Agent 的外部经历和会话管理不是同一问题。目前不足以支持更换模型架构。Pi SDK 小版本变更同样不构成科学主线。

技术前提继续复用 Pi、vLLM、Transformers/PEFT 与单张 RTX 5090 D 32GiB、约 96GB RAM；32GB 无独显笔记本尚未完成部署验收。执行软件、评价和统计见[实施与复现](实施与复现.md)与[评估与统计](评估与统计.md)。正式研究结论以真实执行、外部可检查成果和独立未来任务为准，而不是 Agent 自评、CI 通过或训练参数发生变化。
