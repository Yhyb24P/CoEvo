## 1. 研究目标与可证伪立场

研究资源受限的小模型 Agent 在持续、非平稳且可能含错误、冲突、撤回的人机交互中，如何选择经验的表示、存放位置与更新方式，使其获得可迁移的能力收益，且不会因过度固化而造成负迁移、遗忘或错误沿用。

**主问题 Q1——经验如何归属与固化？** 对一次交互的证据，应该不保留、保留实例、提炼带条件的外部技能，还是进入参数学习候选？这种选择是否比简单保存/检索规则带来独立的跨任务收益？

**主问题 Q2——参数更新是否提供独立且值得付出代价的长期收益？** 在匹配来源、合法训练信息、工具、任务和资源条件下，外部经验与参数学习分别贡献多少，是否存在互补或相互干扰，旧能力与撤回行为受到何种影响？

**主问题 Q3——是否存在模型→经验/选样→模型的双向反馈收益？** 更新后的模型若帮助提取经验或选择训练候选，是否能在相同信息机会和资源预算下提高后续模型能力？抑或只是多看任务、更多计算、测试集适配或更高初始能力造成的表象？

Q1/Q2/Q3 均允许零收益或负收益。学习既包括更新外部状态，也包括参数变化；“协同进化”专指经过控制的双向反馈增量，**不**以持续运行、参数哈希变化、训练损失降低或自评分数上升代替。首次实际 LoRA 候选旧任务由 3/3 降至 0/3 是工程试跑中的负结果：训练数据仅 6 条、327 监督 token、6 步，不能归因于某个抗遗忘算法的缺失，也不能据此否决参数学习。一次 131072-token 资格成功仅支持该具体长文本定位与工具续接场景，不代表真实长任务可靠性。完整依据见 [工作站研究快照](../experiments/workstation-rsi/review_snapshot.md)。

创新性边界：技能/记忆共演化已见 WikiSkill、MSCE 等直接相关工作；模型更新候选由外部验证、抗遗忘 LoRA 和 Agentic RL 亦非首创。本研究可能形成贡献的是**受来源与作用条件约束的跨层固化决策、可撤回性与参数收益的联合评价、以及共享候选池与真实闭环互补的双向反馈归因**。是否具备发表价值取决于与直接相关工作的实证比较，而非机制命名。

## 2. 研究对象、学习动作与固定条件

沿用四种分析因素：`K` 指令来源/作用域/生命周期管理；`R` 外部经验的构造、选择与运行时检索；`W` 模型参数或 Adapter；`S` 训练候选的提议、选择与准入。它们是**实验因素，不是必须拥有四套服务的系统架构**。外部事实、工具观测、权限和隐藏答案在语义上与上述因素区分。

对一项证据 `e`，学习决策 `a(e)` 的研究动作集为：

1. `discard_for_learning`：不转为长期可用信息，仍可保留合法审计痕迹；
2. `episode`：留存原始交互与验证证据，但不作为下次任务的无条件提示；
3. `skill`：形成带适用/不适用条件、证据、版本和撤回路径的可调用程序性经验；
4. `weight_candidate`：在独立 `train_policy` 许可和正确目标确认后列入参数训练候选池，**不等于**立刻训练或发布；
5. `invalidate/revert`：因过时、反例、撤回或回归证据使经验失活/回退模型版本。

这不是强制的 `episode→skill→weight` 升级链；多种表示可以并存，且同一证据可同时有训练禁止和当前使用允许的政策。会变化的用户偏好、账户权限、任务路径、撤回状态、私人内容等原则上不得无条件写入共享参数。稳定程序性行为可以进入 W 研究，但必须检查来源授权、训练目标与撤回后残留。模型可提议抽象、置信度、选样或更新计划；检验事实、权限、最终发布由与待评估模型相分离的机制处理。

固定工作站主平台：RTX 5090 D（约 32 GiB 显存）、约 96 GB RAM，`Qwen/Qwen3.5-4B` 原始权重 + vLLM 为当前已试跑组合，沿用 momo-code 接入复用的 Pi SDK 执行机制（文件 read/write 已实测，任务所需终端等能力待验收），BF16 LoRA/PEFT 作为参数更新基线。笔记本只在工作站主要研究及回归完成后进入最终部署验收。工作站模型推理须实际支持至少 131072 输入 token，且保留生成空间；128K **训练序列长度**不是先决要求。底座与运行栈的进一步更换必须登记新比较，不在主实验中无记录切换。

## 3. 任务生态、反馈与数据流

正式主证据需要同时具备两种互补来源：

- **真实工作流**：在 CoEvo 开发仓库之外的受控代码/文件/终端等独立任务环境，由本地模型执行、用户提出任务并在需要时纠错，记录真实工具状态和可核验最终产物。真实用户材料逐项依既有授权纳入；默认不得从私人交互自动生成训练样本。外部研究助手提供的示范/修复标为 `teacher_assisted`，不能算作 4B 学生自主产生的证据。
- **受控前瞻任务流**：由研究者预先设计或生成、可重置、可执行核验并可注入指令变化与错误反馈的任务，用于任务边界与反事实干预。固定反馈机会，允许多条有效执行路径。合成文件排序/求和/去重只保留为接口冒烟，不充当泛化主证据。

首批研究任务优先覆盖**多个操作程序族**（例如多文件重构与测试、结构化文件及依赖约束处理、可恢复的工具失败处置），并在每族内覆盖：`transferable`（经验适用）、`unrelated`（无必要迁移）、`reversal`（相似但条件/有效指令反转）。真实任务的任务族和覆盖深度以可复位性、核验质量及试点统计决定，不机械要求首轮完成原 v0.4 所列六个领域。

每条任务进入系统前保留来源链、许可、时点、当前有效指令、适用条件、工具版本、前置环境、最终结果核验与反馈出处。经验抽象、改写、对比反例、教师示范和训练候选均继承源簇及其曝光记录。用户纠错是任务意图/偏好等方面的强反馈，但不能单独证明数值、代码或外部事实正确；模型自评只用于提出候选或诊断，不作为正式真值。

使用 `L` 学习流、`D` 开发、`V` 选择、`G` 发布回归、`H` 封存确认。将语义/程序模板及其派生链进行来源级与任务结构级隔离。`H` 从不进入检索、训练、候选排名、超参数选择、周期发布或教师补写。对每个研究问题分别预注册主要的实例迁移、程序结构留出和时间前瞻终点；结果归因的精确定义见评估协议。

## 4. 研究 I：Q1 经验表示、适用边界与固化选择

**目标**：分别检验有效指令生命周期管理与条件化经验提炼的贡献，以及何时应拒绝或撤回经验；此阶段固定 `W0`，先控制参数因素。

**I-A：指令生命周期的独立比较。** 固定 `R0/W0`，用 `K0`（已有来源标识、任务/项目匹配、最新明确要求和撤回状态的强简单规则）对比 `K1`（额外处理作用条件、休眠恢复、局部替代和派生链撤回）。共享原始用户输入与执行权限，不借更多历史或改变模型参数取得收益。以行为 FAR 降低为主要效应，FDeR、ETS 与应行动覆盖度作联合限制；有效集合判定错误和执行行为错误分开报告。只有在这项比较的 D/V 证据足以选定合理 `K*` 后，后续经验实验才固定 `K*`，不把 K1 的收益误归因于 R。

| 组别 | 同源历史证据的运行时处理 | 识别对象 |
|---|---|---|
| `M0` | 不使用跨任务历史；正常当前任务事实仍可用 | 冻结模型零经验参照 |
| `M1` | 检索原始成功/失败片段或常规摘要；按来源去重 | 普通记忆与压缩经验 |
| `M2` | 与 M1 同一合法证据池，提炼适用条件、反例、核验依据的程序性 skill；检索时条件筛选 | 抽象及条件约束的联合效果 |
| `M3` | 使用 M2 同一技能库，但增加明确失效/撤回/替代生效检查 | 生命周期控制的增量贡献 |

严格区分 `K` 与 `R`：I-B 的全部 M 组固定 I-A 选定的 `K*`，共享相同的当前有效指令和实际权限；`M3` 只改变**经验对象**的失效与适用判断，不能通过提升或取消用户指令来获益。M1/M2 应匹配候选来源、检索次数/上限、运行时 token 上限；抽象与核验调用及人工作业成本另计。若要单独归因于“技能抽象”而非条件筛选，增加 `M1+condition_filter` 的诊断对照，并在 V 后冻结，不把 M2−M1 直接称为抽象的纯效应。

另外对学习**决策**比较：`P0` 全部合法实例保留、`P1` 固定简单规则（时间/已验证次数/明确条件）、`P2` 模型提议且由独立检验准入。输入证据与预算保持可比；随机策略作必要的探测基线。Q1 阶段只比较外部保留/技能决策的行为效果；`weight_candidate` 的真实收益与是否值得固化须由 Q2 训练及 H 评价回答，不能凭候选数或自评判断。对随机/固定策略不可进入非法信息的样本采取与 P2 相同的共同合法性过滤。不要给复杂策略独享额外教师答案、隐藏检查器或更多可检索历史。

Q1 主终点为未见来源/结构任务的可迁移完成率与撤回/反转条件下的错误复用率，联合有效要求遗漏、应行动覆盖度、调用/推理成本和不必要不行动。自评“技能有用”不计成功；技能能否真实被激活、使用和产生可复核结果分别记录。参数固化在下一研究中比较，不由此实验判定所有信息永远不应训练。

## 5. 研究 II：Q2 参数增量、学习配方与遗忘

**目标**：在可比资源下判定 W 是否能增加不依赖运行时检索的程序性行为能力，并评估 `R×W` 交互、撤回残留和负迁移。

首先建立有意义的参数学习基线：真实完整工具轨迹（包括读取、正确动作、观察后停止、失败纠错与恢复），仅对已核验的正确 Assistant 行为计算 loss。CoEvo 当前仅监督局部正确写入动作的试跑应保留作诊断，不作为唯一 SFT 规范。共享的训练合法性、来源划分、chat template/tool schema、有效监督 token 定义、Adapter 保存/加载都必须通过资格核查。任务难度在 D 上校准，避免原始 W0 已 100% 通过导致没有改善空间。

**主要 `2×2` 对照**：

| 单元 | 经验访问 | 参数状态 | 科学含义 |
|---|---|---|---|
| `A=R0W0` | 关 | 冻结原始 W0 | 基线 |
| `B=R1W0` | 开 | 冻结原始 W0 | 外部经验独立增量 |
| `C=R0W1` | 关 | 固定训练配方的候选 W1 | 参数独立增量 |
| `D=R1W1` | 开 | 同一候选 W1 | 交互与参数在记忆存在时的增量 |

为识别同源经验的存放位置，主 `2×2` 的 R1/W1 使用从同一 **L 中允许训练的证据源池**构造的冻结经验库/参数训练集；另以含不允许训练但可检索资料的真实经验库作外部效度附加分析，不把这种信息权限差异归因于 W。严禁只给 W1 训练较容易的来源或让 D 单元获得更多当前任务事实。定义 `ΔW0=C−A`、`ΔR0=B−A`、`ΔW|R=D−B`、`I_RW=D−C−B+A`，均用同一 H 面板的预定义风险差或 ETS 差估计；联合收益不默认要求 I_RW>0。R1 带来的信息本身就是处理因素，不能声称 R0/R1 拥有相同历史知识；按同一当前事实、整体 token 上限、检索配额控制，并另设等 token/等计算成本的敏感性对照。

在确定能真实完成参数更新并存在可比较任务难度后，分层研究数据与优化机制：

- `W1-random`：共享合法候选池内的来源去重、分层随机选样，完整轨迹 SFT；
- `W1-selected`：相同候选池、监督 token 与类别/轨迹长度配额，增加来源/适用性/纠错价值选择，以识别 S；
- `W1-replay`：与选样组可比的总监督 token 中留给历史 L 来源一项**冻结的** replay 比例，并与等 token 的新样本组比较；
- `W1-controlled`：若已复现遗忘，再选一个有代码、可在本卡重现的干扰控制方案（如 FINCH 或 SLoRA-Post）与经合理调优的普通 LoRA 比较，不因论文新颖而同时堆叠多算法。

这四项不是必须一次性展开的完整矩阵。数据配方、优化器规则、LoRA target modules 和 prompt 模板的变化分别成组比较；前几步诊断需区分只写入目标、完整轨迹、学习率、Adapter 加载与推理行为。对 DeltaNet 投影覆盖另立兼容性及匹配可训练参数预算的比较，不能把“更多训练参数”误称“新架构更优”。如普通 SFT 和 replay 已提供可靠收益，复杂算法保留为可选对照；即使普通 SFT 无收益，也不能未经诊断归咎于参数学习范式。

在 `R0` 上独立检验 W 的增益，`R1` 上检验部署时的附加价值；对旧能力、条件反转、撤回后残留行为分别报告。版本接受依据 G，H 只用于独立科学结论；接受的 W 不等于底座必须永久合并，原始 base、数据 manifest 和 Adapter 可回退。DPO、Agentic RL、专家路由与结构扩展仅在其特定问题出现且有可靠反馈/资源证据时进入后续研究，不列为本版完成条件。

## 6. 研究 III：Q3 双向反馈机制与长期轨迹

本研究同时开展**识别机制的共享候选池实验**与**检验实际运行的闭环实验**，前者不代替后者。

**III-A：固定数据机会下的选择器效应。** 每周期产生对所有组相同的、事先冻结或按来源配额平衡的合法候选池 `P_t`，同一候选在训练中具有同样的核验信息。比较：

- `SF`：由冻结 W0 的模型辅助选样；
- `SU`：由该组上一周期已接受的模型辅助选样；
- `SR`：来源/任务类型分层随机选择，匹配数量与监督 token；
- `SH`（诊断上界，可选）：独立人工或强教师选择，完整记录额外标注成本，不当作学生自主收益。

选样提示、允许的上下文、选样次数、核验器与最终训练预算冻结。来源池的构成、学生/教师产出的比例预先固定；如池由不同模型生成，记录来源并平衡或对来源分层，使“生成能力变化”不混入“同池选择能力”。各组按预冻结规则从各自前周期已接受权重继续，交叉重训诊断另外使用完全相同前周期 checkpoint，拒绝发布也算结果。在指定周期进行交叉重训：从**同一**前周期 checkpoint 分别训练 SF/SU 选出数据，检查数据差异本身是否影响下一步增益。选样收益只能从该实验的配对估计声称；闭环中的行为更强可能来自初始参数能力。

**III-B：端到端闭环的政策效应。** 让各组各自执行新的真实/受控任务、产生观察、提出经验、抽象技能、选择或拒绝训练，并在相同到达任务流、反馈机会、外部工具及累计资源额度下更新。每条流的策略分支须隔离权威状态库、检索索引、可写文件与模型版本，避免跨分支污染。比较固定学习规则与自适应规则，并加入“经验可更新但 W 冻结”的系统级适应对照。此实验度量**总体政策收益**；因为经历的经验与候选池可能不同，不能把分数差自动归因为选择器本身。阶段内至少含一次实际的更新拒绝、旧版保留与任务续接/中断恢复验证，但这些属于运行稳定性，不预设产生能力增益。

纵向试点仍可使用三个周期、两条独立流，目的仅为估计方差、运行成本和发现机制缺陷。**正式**纵向推断的独立单位是任务流/任务到达序列及训练随机种子，不把同一流的多个周期、工具调用或派生样本当作新的独立试验。持续能力改善必须依据预冻结的未来任务、旧任务保持、撤回行为和资源曲线，而非各周期的历史最佳成绩或重复看到的 G 分数。

## 7. 并行支持性评价：撤回与 128K+

**撤回与失效**：在三项主研究中交叉注入指令撤回、局部替代、经验不适用、工具版本变化、删除许可变化及时间事实漂移。区分 `instruction_invalid`、`experience_stale`、`weight_residue`；前两者是外部状态/激活问题，后者是模型经训练后在禁用记忆与充分提供新有效指令时仍沿用错误历史行为的现象。逐项报告成功撤回延迟、错误复用、有效要求遗漏、撤回后行为残留及能否通过 Adapter 回滚恢复。不能宣称外部 tombstone 已删除模型权重中的信息，也不能以“模型不行动”换取漂亮的误激活率。

**长上下文**：同一 4B 模型和工具条件下，对 32K/64K/128K（必要时延伸至原生更长能力）做含分散证据、多轮工具返回及无关干扰的任务梯度；同时比较固定有效证据量的短窗口检索/摘要与直接长上下文。控制证据位置、长度、干扰比例和 token 预算，不把更多可见证据造成的收益直接归因为上下文窗口。参数更新后复测同一能力面板的独立实例；结果只支持当前模型、任务与后端条件。

## 8. 实施顺序、资源与判断边界

当前工程资格试跑已完成，正式研究尚未启动。任务与交付依赖统一维护在[项目现状与任务路线](07_项目现状与任务路线_2026-10-13.md)：建议下一轮交付 T00–T04，不直接继续原合成任务三个 RSI 周期。CoEvo、被研究 Agent、独立任务环境、学习模块与评价模块按职责区分，无须拆为独立服务；`rsi.py` 负责调度而非承载全部研究逻辑。

工作站先完成执行资格和第一次参数退化的诊断，不需要先等待六大领域、所有算法或新底座复现。后续研究 I 与研究 II 可以并行建设，不以“经验库达到饱和”作为 W 的前置条件；两者具有可比较的稳定版本后再开展主 `R×W` 评价。研究 III 需要前两个研究已能产生真实候选和参数版本，但可先用受控任务流测试状态恢复。工作站研究/集中评价完成后再进行笔记本 GGUF 量化、128K+ 与行为回归。

资源以实测的候选产生、推理、核验、训练、评估和人工复核成本制定。v0.4 的 88 GPU-h 是试点**建议上限**而非已经实测或不可更改的承诺；正式 H 前依据 D 的难度、方差和吞吐规划，若不足则收缩问题或调整预算，并标明证据精度。时间并非唯一成本：监督 token、上下文 token、工具调用与候选失败、重复训练、教师/人工服务都记账；累计质量—成本曲线必须可对比。

允许出现“仅外部经验有效”“仅 W 有效”“R 与 W 分别有效但无正交互”“固化选择不优于固定规则”“闭环稳定但没有协同收益”“模型更强反而使旧经验残留更严重”等结果。只有在独立、可复现的纵向比较中排除额外数据机会和预算解释后，才使用“协同进化”一词作为性能结论。
