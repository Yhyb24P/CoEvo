# CoEvo 实施与复现边界

本文只描述**当前可用实现、应保持的数据语义和持续研究的工程原则**，不规定新的运行授权或微型实验矩阵。科学问题见[研究方案](研究方案.md)，独立评价见[评估与统计](评估与统计.md)。项目正常开展研究与开发，接受版本仍为 W0，候选尚未晋升；阶段事实以 [实验记录](../experiments/real-work-foundation/stage-update-2026-10-14.md) 和实际代码/运行产物为准。

## 现有系统和研究数据

主模型 `Qwen/Qwen3.5-4B`，工作站 RTX 5090 D（约 32GiB GPU、约 96GB 主机内存）；Pi SDK/momo-code 执行 Agent、vLLM 推理、Transformers/PEFT BF16 LoRA 离线学习。32GB 无独显笔记本仍需独立部署验收。现有 `src/coevo/` 中已包含工具与状态、原生会话续接、目标级数据准入、监督训练、开发选择器和评价入口，但它们不是一个经长期真实任务验证的自动 RSI 产品。

工程检查 `PYTHONPATH=src python -m unittest discover -s tests -v`，Pi 脚本语法 `node --check scripts/pi-project-agent.mjs`。可选运行环境缺失时会跳过部分集成测试；GitHub CPU CI 不证明 GPU 结果。已完成的监督/选样/记忆试跑及复现入口统一见[本批复现索引](../experiments/real-work-foundation/REPRODUCE.md)。

## 从任务经历到训练

学习输入保留原始任务与当前有效要求、工具 schema、模型边界处的真实消息/可见动作、工具返回、环境状态变化、用户纠错、分支/重试、部分工件与最终检查。隐藏模型推理不伪装成可见计划；教师提供的代码、示范和恢复建议标注来源。每条派生样本继承源簇与曝光集合，不因摘要或复用产生新独立样本。

原生上下文提供当次连续学习；外部 instance/skill 提供跨任务检索；权重候选学习稳定可迁移行为。临时账户、路径、授权、私人事实和撤回状态留在外部。Instruction、Experience、Observation 与 TrainingCandidate 语义和权限不同。工具/文档是数据来源，不能提升权限；一次实际任务授权应允许其范围内的正常读写，不得演变为每步重复许可。`store / activate / express / train` 是不同用途边界；撤回外部经验不等于权重遗忘。

正确 Assistant 动作、观察后判断、询问、合理停止和恢复可作为监督目标，但需实际证据支持对应目标。失败动作及工具返回保留为上下文，不因 episode 最终成功而全部变成正标签。纠正动作改变状态时，后续工具返回需真实重新执行。SFT 采用同模板的目标 mask，并记录监督 token、输入上下文、训练模块、优化步、实际梯度与 Adapter 版本。Replay、复杂优化器或抗遗忘机制只有相对于简单正确行为学习确实有新价值时才引入。训练前检查完整数据、配置、预算、环境与停止条件；是否开展推理、训练或 RSI 周期依据具体研究需求及用户指令，不受分支工作方式约束。

## 长期轨迹与 QwenGyre

[QwenGyre](https://arxiv.org/abs/2609.33848) 可借鉴的对象是长执行轨迹，不是云端资源调度。当前已有 Pi 会话和分支/续接证据，但尚无 QwenGyre 式完整 prefix-shared tree、策略优化器和长期 RL。需要时按模型边界保留 token 序列、前缀分叉关系与工具证据；共享历史只存一次，训练片段按来源任务合理加权，避免长轨迹/多分支因重复采样支配损失。超时的工件可以在检查器确实覆盖的范围内赋予部分完成信息；检查器故障不能当任务零分。应先观察实际长任务中分支量、重复 token 和收益，再决定是否实施去重或 trajectory-level RL；无需为单卡复制 Elastic Scheduler。

128K 一次输入定位和工具续接已经工程验证；实际长任务应另测上下文增长、条件改变、真实工具链、吞吐与工件正确性。128K 训练序列不是项目起步要求。模型/Adapter 高精度行为与未来 GGUF/量化部署分别比较，不将后端变化误称权重学习收益。

## 实验工作方式与版本

本项目只保留 `main`：直接开发、提交和同步 GitHub，不默认建立开发分支、PR 或审批流程。main 提交自动运行必要工程 CI；Git 提交记录研究进展，重要阶段可用 Tag 固定版本。此前阶段性暂停保留在历史记录中，不构成项目终止或禁止后续研究的现行约束；仓库不归档。

`experiments/<study>/` 保存不可变的来源清单、配置/代码/hash、原始产物受控位置、真实结果及失败；公开仓库只留非敏感索引与聚合，私人原文、权重、凭据与可恢复私人快照不上 Git。开发可记录简短决策及失败，正式结果应可重建，并确保不同策略的状态库、经验、权重与可写工作区隔离。

工程变更直接修改唯一职责的源码与本文档；结果写对应实验目录。不为一次故障另建导航、临时计划、版本并行规范或猜测性 fallback。测试围绕受影响的真实行为及关键契约，阻断性错误修复后复测相应路径，不将安全/权限/来源控制删作“简化”。依赖由 `pyproject.toml`/`uv.lock` 管理；确认可在已支持的运行环境中构建与加载。只有重现困难、资源瓶颈或明确的新研究假设，才增加层级、后端、模型或自动调度。

旧 v0.4/v0.5 研究设计及一次性试跑指导已保存在[固定 Git 历史](https://github.com/Yhyb24P/CoEvo/tree/960cabc9af8dd914f76e149866d7bef768bb6022/docs)，并不自动覆盖本版原则。旧实验的数值、冻结条件和数据不因为文档删减而重判。
