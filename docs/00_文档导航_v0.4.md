阅读顺序为研究方案 → 评估与统计协议；实施时再按需读取数据协议和双机协议。证据文档提供论证，不额外创造实施前置条件；记录模板提供填写结构，不规定科学结论。

发生冲突时，按各文档的唯一职责修订：研究方案负责实验因素与比较，数据协议负责对象和准入，评估协议负责指标与推断，双机协议负责资源及运行。正式实验的冻结记录注明所用文档版本；后续修订仅适用于另行登记的实验，不能追溯改变已完成实验的判断规则。

当前路线优先复用开源 Agent、成熟任务/检查器和本地训练组件，主要开发交互经验管理、参数学习与双向反馈。当前实施顺序为 A 工作站环境与 128K+ 底座资格 → B 真实学习闭环 → C 至少三周期工作站 RSI → D 笔记本最终验收；科学实验仍使用 E0/E1/ER/ET/EC/EL。首批任务限定为代码、文件与终端操作，六类通用任务为后续扩展。工作站为主实验平台，8K/16K 仅作接口诊断；冷文件优先放在 `/mnt/e/CoEvo` 并链接到项目。momo-code 为运行基础，Pi 仅在确有接入障碍时作为替代；不同时维护两套运行框架。既有授权范围内的可回滚工作持续推进；未确定的训练参数或不充分的统计精度分别记录为运行选择和结论限制，不阻塞整个项目。
