# 监督覆盖对照与复现

当前共享实现 `coevo.supervision` 从已核验 student 目标构建同轨迹数据。output-only 与 full 使用完全相同 messages/tools，只改变监督轮次：前者仅正确 write 或实际改变输出的 bash，后者覆盖这条输入清单中全部已核验 Assistant 目标。未核验解释、错误动作及工具观察仍留在原上下文，不进入正向 loss。full 不等于所有 Assistant 文本均正确。

三组为 output-only、full、full-replay；学习来源完全一致，replay 使用来源簇不重叠的冻结 W0 轨迹。两种视角分别记录：same-exposure 对每条序列一次曝光（加入 replay 会增加预算）；token-matched 按完整序列重复，使监督 token 接近同一上限。重复次数、优化步数、学习/replay 比例与上下文成本必须同时报告。不能将近似等 token 称为等计算，也不能同时宣称相同曝光与相同预算。

## CPU 检查


## 私有数据预算预览

以下环境变量由操作者设置为实际路径；输入是目标证书 JSONL，tokenizer 是已存在的本地模型目录。使用尚不存在的输出目录。

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.supervision \
  --learning "$COEVO_LEARNING_A" "$COEVO_LEARNING_B" \
  --replay "$COEVO_REPLAY_A" "$COEVO_REPLAY_B" "$COEVO_REPLAY_C" \
  --tokenizer "$COEVO_TOKENIZER" --config "$COEVO_CONFIG" \
  --out "$COEVO_PREVIEW_OUT" --budget 1101 --tolerance 0.03
```

生成三份数据、各自两个设计配置及 plan.json。每个样本继承证书，使用实际模板核对 mask 边界；超长样本拒绝，不静默截断。不满足容差的完整序列预算组合会报错，先做长度预览再冻结预算，不能依据训练收益调整预算。

训练入口读取配置中的 training_schedule，以合法数据行索引记录重复，不虚构新来源或目标。显式 schedule 使用 passes=1；每组从同一 W0 出发，不传 previous-adapter。数据、模板、配置、种子、预算、独立评价与停止条件冻结后才运行：

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.train \
  --config "$COEVO_ARM_CONFIG" --dataset "$COEVO_ARM_DATASET" \
  --adapter-out "$COEVO_ARM_ADAPTER" --seed 17 --passes 1
```

## 当前边界

最早的两个既有 L 来源及三个 W0 replay 来源仅用于入口预览：1092/1071/1101 token、8/6/11步，不构成正式能力对照。当前已扩为同批12个episode、四个族级来源簇；新增评价与六组配置在训练前冻结，实际运行状态见阶段记录。

工作站配置保留本机实际取值。记忆试点可通过 --source 覆盖，Agent 提议试点可通过 --learning-root/--correction-root 覆盖；Marko 入口要求显式 --source。当前不存在正式 Q3 SF/SU/SR 等预算交叉重训证据。开放原生建议已可通过实际工具引用目标，其工程接通不能替代选择器因果比较。

远端验证证据：[8104c54 的 CPU CI](https://github.com/Yhyb24P/CoEvo/actions/runs/38507811138)。Python 3.12/3.13 各执行34项、跳过6项，均成功；本地40项全部执行通过。该次 CI 不执行 GPU 实验。

## 扩展共享 L 池与开放建议的实际引用

`coevo.workflows` 在一次冻结批次中生成多变体 L 任务，使用相同任务执行、结果核验和证书机制。当前采集12个episode、四个程序族来源簇；同族变体不算独立统计来源。每个episode至多一次外部纠错，正常和失败原始轨迹均保留；同源已有读取可在纠错后独立核验，但旧错误动作不能因最终成功而获得监督。

Agent 直接续接完成工作/纠错的真实 Pi 会话，自由讨论是否学习、学习什么。若要落实选样，可调用 `nominate_training` 引用外部已经核验的动作编号；参数只描述执行引用，不是固定经验提议 schema。工具核对实际监督 token 和至多两个动作，允许空列表撤回。既不从自由 prose 猜测最终选择，也不把 prose 自动标成正确训练文本。最后一次提名被拒绝或会话失败时，不隐式采用旧接受决策。

运行参数均显式给出，输出目录需不存在：

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.workflows \
  --config "$COEVO_CONFIG" --out "$COEVO_COHORT_OUT" \
  --batch "$COEVO_BATCH" --variants 3 --seed 17
```

输出 manifest、每个episode的原始/纠错/学习轨迹、候选证书、`candidates.jsonl` 与 `agent-selected.jsonl`。前者用于固定监督覆盖比较，后者用于开放决策的独立记录，不能混同。来源仅L，不导入旧D/G/H任务内容；未来D/H评价与训练分开生成。采集已结束，初始3/12、第一次外部纠错后5/12；同批剩余7项通过额外定向教师反馈完成。后者是辅助完成，不是自主12/12。首次错误准入的只读循环目标已重新核验、撤回，原摘要保留。


## 六组矩阵与共用评价

最终12条完整会话最长11495 token，不裁剪历史。局部/完整目标使用同一规范模板的完整token序列，只改变核验轮次的mask；模板插入generation标记后的token必须与原模板完全相同，避免多轮历史因重复渲染而错位。工具观察及失败动作不进入loss。

`--equal-updates` 用显式microbatch分组和监督token加权累计梯度，控制Adam更新次数。同曝光三组分别1734/3401/3649监督token、12次更新；近似等监督预算分别10404/10203/10451 token、36次更新，microbatch数72/36/39。重复完整序列是预算分配，不能当作新增来源；同一次更新中的重复在当前零dropout设置下不会增加独立信息。实际上下文token与耗时另报，不宣称等计算。

`--loss-mode selected-logits` 只投影有监督的因果预测位置，保留全部输入上下文；CPU张量测试验证loss和梯度与dense shifted CE一致。未知模板拒绝猜测。该实现需要模型支持logits_to_keep，不能默认所有底座均可使用。

矩阵生成后，使用共享入口冻结、执行。所有路径由操作者显式设置；六组均从W0出发，不接续其他Adapter，seed=17。冻结16个同族新输入D与3个旧G输入，所有模型使用相同Pi工具与采样。G的执行协议统一后重新测量W0，不直接与历史调用结果比较。D是同程序族实例迁移，不是独立来源H。

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.supervision_trial \
  --matrix "$COEVO_MATRIX" --config "$COEVO_CONFIG" --out "$COEVO_TRIAL"
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.supervision_trial \
  --out "$COEVO_TRIAL" --run
```

输出原始任务、训练日志、参数哈希、每组独立Adapter和配对评价。已启动目录禁止隐式重跑；保留失败目录后再确定恢复操作。入口不晋升模型、不启动自动RSI，不将本矩阵解释为Q3或R×W。
