日期：2026-10-13。本文说明为何修订，不规定额外验收步骤。审查对象是上传的《agent_model_coevolution_experiment_plan_v0.3.md》，SHA-256 为 `dc6262bd2abc99e011ad17ab37bd21d795f5218684d29cf8cab1cd86c19289e6`。一手资料经过候选检索、原文定向核查和关键反例检查；目标机器、实际代码与训练产物未提供，因此不评价它们是否已完成。

## 1. 决定结论的修订

**收益归因。** v0.3 已要求区分外部状态与参数，但 E1 同时讨论生命周期和经验，E3 的 Agent 因素也未明确检索可见性。一个版本若既改变有效指令集又提供更好的历史答案，ETS 提高不能定位到来源控制。v0.4 将 K、R、W、S 分开，先做无经验的 K 比较、固定 K 的检索比较和关闭经验的权重比较，再测交互。实际授权代理和当前任务事实在各组一致。

**训练对照重叠与构成混杂。** v0.3 的 M1 已核实成功，M2 再加入结果验证及来源去重；M3 又增加恢复、冲突和不调用样本。原有差异可能来自重复权重、难度、目标动作比例或不同能力覆盖，不能逐项归因。v0.4 的 T1/T2 共享合法成功池、来源去重和分层配额，仅改变研究性的选择；T3 是另一纠错配方，其净效果与“某一种边界机制”的独立贡献分开。

**强模型完整轨迹不一定是可靠默认。** [S02] 在七类企业任务上报告了 Qwen 学生在已优化 Agent 下完整模仿的回退，另一 Gemma 学生在 Webarena 上也出现回退。局部纠错较好，但论文的失败分类使用模型判定，数据配方和算力也与本项目不同，因此既不能预言本项目必然回退，也不能直接照搬收益。v0.4 增加学生自身状态的正确续接；保持前缀分布，同时重新执行纠正动作，防止改调用却沿用不再成立的后续结果。

**多周期选样的混杂。** v0.3 E5 比较固定选择规则与更新模型辅助选择，但没有规定两者看到的候选池是否相同。若当前模型更会生成轨迹、遇到不同失败或消耗更多判断 token，变化不只是选择质量。v0.4 先在共享池、相同配额和选择上限内比较；真实各自采集的闭环另报告总效应。共同 checkpoint 的交叉重训仅作为定向诊断。

**封存原则尚未操作化。** v0.3 提到了 regression/sealed_test 隔离，但未明确每周期结果是否影响下一周期和发布。即便仅返回通过/失败，也属于选择反馈。[S13] 提供了重复自适应分析的理论动机，并不要求本项目部署复杂的差分隐私机制。v0.4 允许 D/V/G 正常迭代，将周期 H 反馈延迟到学习流完成后，保留来源与曝光记录。

## 2. 最近研究与创新性边界

直接相近研究使以下宽泛贡献表述不可成立：

- “首次保持记忆来源与权限”：AuthMem-Bench [S04] 和 PPMF [S05] 已直接研究摘要后的权限放大。
- “首次解决撤回旧记忆”：记忆检索中的撤回执行已有专门实证 [S06]。
- “首次将经验写入 LoRA、再改进经验提取”：TMEM [S07] 已提出参数记忆与提取行为的联动，主要是在 episode 内更新。
- “首次区分持续学习的迁移与稳定性”：AgentCL [S03] 已区分可复用关系和独立任务；记忆层的干扰也已有研究 [S08]。
- “首次联合修改 Agent 与权重”：Agent—模型相容性 [S02] 和 RSIGym 的 Data/Harness/Joint [S12] 提供直接相关框架。

更有价值的研究位置是：在受限本地部署与离线单卡更新中，用显式来源/作用条件约束训练准入与选择，实证判断它是否优于强简单基线、普通检索和分层随机 SFT，并识别权重收益在哪种任务关系上成立或消失。

这仍是待验证定位。若 T2 不能优于 T1，或 K 的来源控制效果与已知方法一致，则结果应写为复核、负结果或资源约束分析，不能仅靠对象重新命名维持创新性。若本版有正结果，论文需再对最接近的可复现方法做同预算比较；本次方案审查不是完备的新颖性认证。
