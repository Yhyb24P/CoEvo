# 经验反馈修订对照

上轮笔记三得三失，出现字段撤回后沿用旧规则和转义/精度遗漏。本批固定W0，让模型在实际原笔记会话上修订经验，再对独立新输入比较。五组为无历史、旧笔记、仅额外自审、实际反馈修订、完整历史记录。额外自审控制重复思考与更多生成机会；不能把第二次生成变好直接归因于反馈。

两种修订均用SessionManager.forkFrom同一原笔记会话，保留真实SDK前缀、工作轨迹和旧笔记。表达自由，不要求JSON或固定条件白名单；只有具体写文件使用工具接口。反馈只提供已暴露D任务的实际用户要求、成功/失败和失败实际输出，不提供检查器期望答案或新参考代码。修改只能写learning-note.txt，旧输入输出只读。成功写出不等于语义已正确，质量由未来任务核验。

修订笔记继承原L工作和D反馈/开发曝光，标为D且train_authorized=false，不回填合法L或H。本批没有训练、模型晋升或自动周期。新未来任务seed505，旧任务seed404，两者精确输入不重复，仍为相同程序族与干预结构，不能称独立来源H或结构外泛化。

每组执行同一12任务，初始上下文通过实际SDK历史/模板匹配，使用明确无事实/指令的中性填充，当前任务放在填充之后；实际请求和API首轮token另核对。采样temperature0/seed17、权限、12次工具上限一致，各工作区只含当前输入及空输出。全部任务顺序seed17随机，后续调用与实际成本分别记录，不宣称等计算。

先冻结未来面板、干预、来源和预算算法，修订后但评价前冻结笔记版本、具体提示和token计划。输出目录不能已存在，不因观察超时重启活任务。最长wall5400秒，实际长任务按预计时间休眠后回收。

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.note_revision \
  --config "$COEVO_CONFIG" --parent "$COEVO_CONTEXT_PARENT" \
  --out "$COEVO_REVISION_OUT"
```

当前已运行两个反馈不含检查器答案/新面板不重叠用例和三个既有预算/可逆信息/条件用例，均通过；实际修订与60次评价已完成。不预设修订一定有效，旧版及失败记录保留。原始请求、笔记和会话仅保存在忽略的本地目录。

## 本批完成结果与暂停交接

八次原生笔记修订与60次未来任务评价全部完成，实际总耗时约519.5秒。无历史5/12、旧笔记7/12、仅自审11/12、反馈修订7/12、完整记录11/12；每组使用同一12任务。首轮实际请求与计划token差值、API报告与实际请求差值均为零。评价耗时合计分别约72.9、54.3、60.9、69.9、62.8秒，不含修订生成成本，不宣称等总计算。

本批反馈修订未超过旧笔记或仅自审；自审与完整记录同为11/12只描述总分，不证明统计等效。四族、单seed、同族新输入的开发试点不足以确认普遍收益，更不能把反馈修订效果直接归因于双向协同。修订经验继承D曝光，不回填L；无参数训练、无H、无晋升。原始笔记、请求和会话继续仅保存在本地冷盘。
