# AGENT-MODEL-RSI 评估与统计

基于用户 v0.5 评估设计和最新日常工作定位。本文件定义正式科学评价，历史 v0.4 试跑不按新阈值重新判定。具体样本规模和阈值在 D 上估计、正式 H 前冻结。

## 数据、评价单位及许可

episode 为一次任务和其工具、指令、反馈、最终工件；source_cluster_id 合并原始任务及派生摘要、纠错、技能和训练样本；program_family 标记程序结构；stream_id 标记长期任务流。横截面归因以来源簇为主要单位，多周期 Q3 以独立任务流为主要单位。训练种子与同任务反复调用不构成新的任务来源。

L 学习、D 开发、V 模型/策略选择、G 发布回归、H 封存确认。H 不进入模型提示、经验库、训练候选、调参或发布判定。先测后学，并保存工具权限、当时有效指令、训练许可、教师/外部示范和所有数据曝光。个人资料只有在获得用途明确授权后才可持久化或训练。

## 结果核验与指标

基于独立于被测 Agent 的实际工件/工具结果检查器，允许等价正确路径。用户反馈确定意图和偏好，不能单独证明事实；模型自评只能提供诊断。

**ETS**：在规定工具、时间和权限内达到全部任务完成条件的 episode / 全部指定 episode，失败、超时、拒绝、错误完成和解析失败均保留在分母。

**FAR**：实际沿用失效指令 / 事前定义的失效机会；**FDeR**：有效指令未得到满足 / 有效指令机会；**SRR**：失效经验被错误使用 / 失效经验机会；**PGR**：禁用旧经验并明确提供最新指令之后仍表现撤回行为的比例；**Δold**：旧能力任务相对 W0 的变化；**FG**：下一周期首次遇见任务的成功率；**SEL**：相同前周期 checkpoint、相同候选池/预算的选样效应；**LC**：分别记录训练 GPU-h、推理 token、监督 token、工具次数、人工分钟和墙钟时间。

新增日常行为配套指标，不能单独替代 ETS：

| 指标 | 分子 / 分母 |
|---|---|
| FCR 虚假完成宣称 | 未实现目标却声称完成的任务 / 全部声称完成的任务 |
| UAR 不必要弃答 | 在已确认可执行、已授权且预算足够的任务上无充分理由拒绝或停止 / 此类可行动任务 |
| BDA 边界决策准确率 | 正确选择执行、询问、拒绝或停止的事前可判定机会 / 全部事前可判定机会 |
| UCR 无效重试 | 无新增信息且无恢复可能性仍重复操作的次数 / 事前标定的阻碍机会 |

“模型实际能否完成”不能根据失败结果事后任意重新标注。报告正确完成与拒答之间的权衡、缺信息乱猜、越权尝试及工具失败后的假完成；系统拦截的错误动作仍需在模型行为层计数。

## 研究归因与统计

Q1 比较 K0/K1、无记忆 M0、普通记忆 M1、条件化 Skill M2 及失效治理 M3，同源证据池、工具权限和检索额度一致。Q2 采用 R×W 的配对 2×2：A=R0W0、B=R1W0、C=R0W1、D=R1W1，计算 C−A、B−A、D−B 与 I_RW=D−C−B+A。普通完整轨迹 SFT 与 SRFT 需分清 4:1 的样本数比例与实际监督 token、旧能力保持及 replay 制作成本。

Q3 同池比较 W0 选样 SF、更新后 Wt 选样 SU、分层随机 SR；从相同 checkpoint 出发训练测 SEL，再比较不同策略在独立任务流中的总闭环收益，包括经验可更新但 W 冻结的对照。严格区分选择机制作用与更多数据的效应。

按 D 中簇内相关、配对不一致与任务流方差确定正式 H 样本数；报告任务来源、种子、失败和 95% 置信区间。可沿用 v0.5 的分层 bootstrap（默认至少 5000 次）及四主要效应 Holm α=0.05 设计；新增日常指标必须提前定义风险门槛，不得在看到 H 后改写多重比较家族。仅有三周期或两条独立流不能声称统计可靠的长期自进化。结论允许仅系统状态改善、仅经验收益、参数负效应或未证明协同反馈。
