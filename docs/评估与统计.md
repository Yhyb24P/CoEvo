# CoEvo 评价设计：完整任务、经历迁移与参数归因

现行[研究方案](研究方案.md)将真实连续工作作为研究单元。评价并不等于对每条工具调用设置一个独立“Gate”；实际工件、反事实对照和真正独立的未来任务才决定研究结论。首个综合工作任务是[2025 MCM C](../experiments/mcm-2025-c/README.md)，但一项公开赛题不能充当普遍泛化的 H。

## 评价对象与来源隔离

- **工作流/episode**：需求、截至该时点有效的指令、数据和权限、原生消息、执行、反馈、最终成果；同一任务的暂停、复盘、纠错和重试都可记录为事件，但不是新的独立来源。
- **source_cluster_id**：关联原题、历史回测、数据扰动、派生任务、模型笔记及训练目标。MCM C 的全部派生任务默认属于同一研究任务来源大簇；不要将“20 个国家 × 3 个年份 × 10 次运行”当作 600 个独立来源。
- **stream_id**：真实连续工作流；Q3 的长期净收益需跨独立流评价。教师辅助、模型独立首次尝试、用户反馈后完成、研究者修复、系统拦截分开标注。
- **L / D / V / G / H**：合法学习资料 / 开发探索 / 机制选择 / 发布回归 / 封存科学确认。来源与所有派生材料继承曝光；评估失败可以触发新的开发工作，但已曝光集不因此“恢复为 H”。

从一开始报告一次完整任务的可核验交付：数据清洗、可执行模型、预测与区间、图表、说明和复现。**实质工作质量**优先于 PDF 外观和模型自评。部分任务成功可分别记录；失败、超时、未完成以及缺权限时正确停止均保留。不可归责的工具设施故障单列，不改写成模型成功。

## MCM C：如何评价综合工作

原题仅允许使用官方五份数据文件进行模型和数据分析；外部资料可以帮助背景解释，不能暗中输入额外奖牌预测数据。依官方题面，最低覆盖的任务要素是：各国金牌与总奖牌预测、误差与不确定性、2028 预测、首获奖牌国家及其概率、项目数量/类型关系、教练效应及三国建议、原创洞见和成稿。答对其中一部分不能宣称“整题完成”；承认无法因果识别教练效应不等于失败，关键是有无方法与恰当结论。

**可自动校验**：输入/输出文件与时间切分；队伍-国家映射；年份、项目字段和缺失处理；模型训练是否读取未来结果；每个被评价的国家是否有预测；预测数值非负、金牌≤总奖牌；可重复生成表和图、进程退出码和代码/表格一致性。奖牌数为计数，区间应在合理非负支持上说明含义。

**可量化模型质量**：按国家/年份配对报金牌/总奖牌 MAE、与朴素基线差异；所有参与国家含零值并提供高奖牌国家/零奖牌国家分层。概率区间同时报告实际覆盖和宽度，可用适用的 proper scoring rule（如 WIS/分位数损失）；首获奖牌要报告预报概率的判别/校准，避免只把预测个数与真实个数相比。2028 真值尚不存在，不能报告实际误差。对项目结构和教练推断使用方法检查与证据边界评审，不让单个 LLM 审稿意见决定正确性。

**可审查科研判断**：预测与拟合区分、假设与代码一致性、模型选择理由、相关与因果区分、无效数据处理、失败原因、结论可复核性。人工评审须事先给出一致的标准且尽量盲化模型身份；模糊“像获奖论文”不是可靠指标。

## 时间泄漏和公开赛题污染

实测官方包的奖牌/运动员数据延续至 2024 年，主办国表包含未来届次；项目表止于2024，但没有历史发布时间记录。不能在做历史回测时简单加载整个 CSV 再只按目标标签年份过滤：未来项目数、未来运动员名单、未来国别映射和预处理统计也可能泄漏。

以预测年份 T 为目标时，训练产物只暴露 **T 前确实可知的结果与辅助字段**。比赛已公布的主办国/项目计划只有在可以证明其在该回测时点已经可知时才能作为预告协变量；没有历史发布时间戳时采用保守屏蔽，并记录因子不可用的假设。2020 届特殊的推迟举办需要区分奥运版次与实际举办时间。

可用 2012、2016、2020、2024 等滚动预测时点检查建模流程；这些是有公共真实结果且可能受预训练污染的**开发/回测**，不构成严格 H。尤其题面第一页直接列有 2024 前七国家奖牌，不能把相应结果“封存”为盲测。2028 是真实前瞻预测、尚无成绩标签；只能检验方法一致性与部分理性约束。纯重命名/随机扰动可以检查工具与推理鲁棒性，但仍属 MCM 来源簇，不能伪装成不同领域的科学确认。

## Q1/Q2/Q3 的有解释力对照

| 问题 | 重点对照 | 能支持的结论 |
|---|---|---|
| Q1 | 固定 W0，当前任务上无历史 vs 原生历史/完整可回放经历 vs 外部笔记/条件 Skill；任务带条件反转、指令撤回或新来源 | 历史是否帮助；摘要是否损失关键适用信息；撤回是否有效。需要记录各组信息及 token/工具成本，不假设等初始 token 等于等信息 |
| Q2 | 相同模型从冻结 W0 出发，合法 L 来源一致，`R0W0 / R1W0 / R0W1 / R1W1` 同题配对；旧任务与独立结构任务同时观察 | 外部经验增量、权重增量、交互和负迁移。不能以不同模型的绝对分数代替参数收益 |
| Q3 | 经过真实晋升的 W1 与冻结 W0、分层简单策略在相同候选池选择，交叉训练后测未来任务；多条独立流复测 | 更新模型是否确实改进后续经验利用或选择。代理 SU 与真实 SU 区分 |

**底座比较与学习比较分开**：当前 Qwen W0 和 Spark 基座候选首先对齐任务、权限、工作区、可见数据、推理预算与原生正确工具模板。合理比较包括双方推荐思考模式的实际成本和共同配置对照，不能因为强制错误模板压制候选，或把 thinking on 与 off 的差异隐藏在“模型提升”中。若将来替换底座，两个模型的 W0/W1 代际分别追踪，禁止直接继承另一架构的 Adapter 或混同数据曝光。

## 统计与资源报告

开发阶段逐次反馈及纠正属于探索，不机械要求逐轮显著性检验。对正式效应按独立来源/独立任务流配对，报分子/分母、各任务类型、效应量及不确定性区间；同源多个问题、工具动作、国家或改写不按独立样本计算。正式 H 的任务结构、来源隔离、主要指标、停止规则和资源预算在查看 H 结果前固定；若后来修改研究策略，需新的未曝光 H。

至少报告：完整任务完成及部分有效成果，真实预测误差/区间质量，重复错误、FCR（虚假完成）、SRR（失效经验误用）、FAR/FDeR（指令生命周期错误）、UAR（无故停止），旧任务遗忘、工具调用、推理 token、训练监督 token、GPU 小时/峰值显存、墙钟及人工反馈。每项风险按实际机会计分，不因没有机会发生而计算成完美通过率；成本不能随意合并成单个“效率分数”。

公开论文与赛题解答的已知信息可能存在于模型预训练中；静态官方回测和人工标注测试都无法彻底排除预训练污染。若没有真正新来源的 H，就明确报告“具有开发性迁移迹象”，**不声称可泛化、可持续或协同进化已获验证**。
