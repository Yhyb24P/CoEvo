# CoEvo 评价与科学推断

评价服务于三个判断：**未来任务是否更好、旧能力与有效指令是否保留、收益能否归因于相应学习机制。** 不为每条工具调用建立独立统计实验；局部工具测试负责实现正确性，完整任务及独立工作流负责能力证据。现行科学问题见[研究方案](研究方案.md)。

## 任务、来源与结果

一次 `episode` 包含任务需求、环境状态、当时有效指令、原生模型上下文、执行与反馈、最终工件。`source_cluster_id` 连接原始经历与全部摘要、纠错、示范、派生训练目标；`program_family` 区分任务结构；`stream_id` 是长期连续工作流。训练 seed、同任务多次尝试、同源变体不自动成为独立研究样本。

成功以受控工具或独立工件检查衡量，容许等效正确路径。完整任务成功 ETS 的分母包含所有指定任务、失败、超时、拒答和部分完成；同时报告部分有效成果与完成成本，不以“做了很多步骤”代表成功，也不将错误完成宣称掩盖在工具返回中。对正常可行动任务必须检查无故拒答、缺参乱猜、无效重复操作和应行动覆盖。

必要风险指标：FAR（沿用不适用的**指令**）、FDeR（有效指令遗漏）、SRR（错误复用失效**经验**）、PGR（关闭经验后仍残留旧行为）、FCR（未完成却声称完成）、UAR（可行动任务无理由停止）。每项有独立、事前定义的机会分母，联合报告任务完成。外部拦截成功与模型主动判断正确分别记录；用户确认偏好/意图不等于数值或工件已核验。

## 证据层次与公平比较

- **开发/探索**：可以反复检查 D、修正工具、训练和实验设计；要保留失败及已曝光信息。开发中出现的 6/16→8/16 之类变化只能生成假设。
- **选择与发布**：V 选择方法或超参数，G 用于接受/回滚候选；重复使用 G 是自适应选择，不能再称独立确认。
- **科学确认**：H 在任务来源、程序结构、主要对照和算法决定之前封存。H 的答案、分数、派生经验不得进入模型、检索、选样和发布决策。根据 H 再调整策略之后，需要新的独立来源作下一次确认。

关键对照按问题选择，不机械铺满矩阵：

| 问题 | 有解释力的主比较 |
|---|---|
| Q1：有效指令与经验 | 固定 W0，先比较简单 K0 与条件化 K1；再固定 K，比较无历史、完整历史/普通检索与适用条件/撤回治理。原生历史、完整记录和压缩笔记的信息并非天然等量。 |
| Q2：参数与外部经验 | 在同一合法 L 来源池、当前事实和工具条件下，用 `R0W0 / R1W0 / R0W1 / R1W1` 同题配对，计算参数增量、经验增量及交互；W1 在 R0/R1 必须是同一权重。 |
| Q3：模型对未来学习的贡献 | 固定共同候选池与训练起点比较 SF（冻结模型）、SU（**已接受的更新模型**）、SR（分层随机）并评价未来任务；另在隔离流中比较完整自适应政策、简单政策及仅更新外部经验的策略。 |

每次比较说明总可见信息、来源构成、反馈机会、当前有效指令、推理/训练预算和教师参与。等监督 token 不意味着等上下文计算、等 GPU 时间或等独立来源。模型训练后的任务首次执行与看过纠错后再次执行分开；教师辅助恢复不能计为学生自主首次成功。

## 推断与报告

主效应按来源簇配对、任务族预定权重和独立训练 seed 估计；多周期按独立 `stream_id` 或配对流分析，不将同一流的多个周期作为独立重复。必要时采用分层簇 bootstrap/层级模型，报风险差（百分点）、区间、分子/分母、各程序族、失败和成本。正式样本量依据 D 的配对差异、簇相关与真实任务成本确定；仅两条流或极少来源不得声称长期显著性。多个主要假设共享错误率控制时于 H 前确定检验家族；开发探索不必每批进行显著性检验。

至少呈现旧能力、撤回/失效、无条件拒答、错误完成宣称及总学习成本。计算成本分开报 GPU 时间、推理/上下文与监督 token、核验/工具调用、人工参与、墙钟；没有依据时不汇总成一个虚构单值。展示零效果、负效果、未晋升与失败实验。有限 H 只能支持其任务分布，长窗口资格和一次成功不能替代真实长任务梯度。

**保留的重要边界**：真实输入的存储、表达和训练许可分别获得；私人会话默认不可训练；新评估集合不能由旧任务的改文件名、改数值或同一生成模板伪造独立性。客观结果的核验边界与安全权限由实际执行层保证，不由被评估模型自行宣告。
