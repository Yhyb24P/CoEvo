# CoEvo 评价与统计：实际工作与 RSI 的可辨识净收益

[研究方案](研究方案.md)确立 Q1 经历、Q2 参数与 Q3 递归改进策略。本文件只要求能改变研究判断的证据，不将每个 read、write、bash、checkpoint 或格式错误变成独立科学核验。

## 完整工作成果与真实来源

一次完整工作流记录真实需求、有效用户指令、原始输入与文件、模型/Harness、实际行动、用户/教师反馈、局部与最终成果、失败、环境和成本。来源与派生关系继承；MCM、python-frontmatter 维护、Palmer Penguins 及其后续反馈均属已曝光 D，不会因切换到 PilotDeck 就转化为未见的 H。L/D/V/G/H 作为学习/开发/选优/回归/独立确认来源标记，不能用多次重复、随机种子或同文档衍生题充当跨任务泛化样本。

主要衡量实际完成程度、成果可用性、事实/计算准确性、必要修改是否覆盖、无关内容是否得到保留、人工返工与重复指导、合理资源消耗和后续工作连续性。正确停止、承认不知道或完成有用部分成果可以如实记录。成功的工具调用、正常退出、有效文件包、CI 通过及模型自称完成都不能单独证明能力进步。

Office 编辑尤其关注**修改完整性与保真同时成立**：Word 段落/格式/引用、Excel 公式/数据/依赖、PPT 布局/图表/备注，以及不应改变的结构。资料与文献整理要求引用可靠、无虚构、版本时效和用户指令一致。科研分析既要复现数值，也要审查估计对象、缺失与样本定义、统计区间、混杂与论证边界。是否采取 OOXML 检查、渲染或人工审阅，由具体工作风险和不确定性决定，而非按每文件固定十道门槛。

两条最新[完整工作结果](../experiments/complete-work/README.md)必须继续按事实理解：软件维护原有 56 项测试通过但用户所需修复失败；科研分析独立复跑一致但区间和调整结果解释有误。反馈后修订若变好，属于有外部指导的当前任务能力，首先不等于 RSI。

## 识别能力变化来源

**即时适应**：在当前会话/原生续接中接受反馈后改正。注明反馈是否包含解决办法、参考代码或直接修复，不算首次独立成功。

**Q1 外部经验**：固定 W_task 和可比较环境，在不同来源的未来工作观察无历史、原生历史、PilotDeck 默认记忆、CoEvo 条件经验/Skills 的收益及负迁移。关注用户临时指令失效、经验撤回、跨 Workspace 污染、检索与人工代价。信息内容差异与 token 数分别记录；记忆被成功存储不是能力增益。

**Q2 模型参数**：训练前后固定来源和主要推理条件，观察 W0/W1 在新任务、旧任务中的真实成果；足够数据时进行 R0W0、R1W0、R0W1、R1W1 以区分外部经历与权重效果。监督候选可来自真实有效部分成果和纠错，但须标明模型独立行为、用户/强模型指导及可信目标来源。不同底座、不同 Harness 的绝对结果差异不等于参数收益。

**Q3 RSI 改进策略**：分开报告研究者改 Harness、Agent 自主提出的修改和 W_evolver/S 更新后在未来更善于选择及实施有效修改。需要实际改动、修改前后成果、代价和新来源的持续收益；比较学习前后进化策略时保持任务模型、修改权、反馈机会与资源相称。仅有修改记录、LoRA hash 变化或自动生成 Skill 均不足以支持 RSI。多轮改善下一轮改进过程的真实表现，是强 RSI 主张的关键。

**上游模块与 RSI 效应分开**：CoEvo 保持独立执行体系；引入 PilotDeck Skill、升级 Pi SDK 或使用参考 CLI 带来的提升，首先归于环境变化。学习比较固定相关执行与模型条件。生产助手可以使用强模型路由，但参考模型的实际介入不能归给本地 W0。

## 资源、确认与结论边界

记录完整任务/工作流及其来源，实际用户返工、工具/推理/训练时间、模型与模板、输入输出 token、GPU 及外部服务成本、外部帮助。 上下文额度注明 SDK 估算或服务实数计数策略；错误中的至少/下界不当作精确 token 数，接口拒绝与模型能力失败分开解释。必要时按独立来源配对报告效应与不确定性，别用一篇论文中多个国家或同一表格几十行充当独立样本。H 必须与训练、规则优选、反复开发反馈的来源隔离；公开榜单和已看过的赛题只能作开发参考。

[OfficeEditBench](https://arxiv.org/abs/2609.34469)与[LongMemEval-V2](https://arxiv.org/abs/2605.12493)提供文件保真、长期轨迹经验的机制检查思路，[Harness²](https://arxiv.org/abs/2610.14224)提供当前任务与跨任务 Harness 进化的对照思路，但不能替代真实工作或自动成为未见测试。只有当评价能排除重要竞争解释、支持重大决策或保护真实来源与权限时，才增加检查工作。
