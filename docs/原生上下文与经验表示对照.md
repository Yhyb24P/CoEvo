# 原生上下文与经验表示对照

本批固定W0，比较无历史、实际Pi原生续接、同一完整历史的外部记录，以及W0在原生会话中自由写出的经验笔记。原生/完整记录控制来源和可见事实；笔记是派生提议，不假定信息完整或语义正确。四族各一个合法L工作来源，未来12个D任务包含普通迁移、条件变化、旧规则撤回，每组都执行同一面板。

原生组调用SessionManager.forkFrom，逐项核对原始SDK消息前缀，不用摘要或导出记录重建会话。完整记录来自SDK实际发送的历史消息；JSON解码可恢复原数据，角色控制标记编码为数据字符，历史权限不作为当前授权。表示和角色语境的差异是本比较的干预，不推断模型存在额外隐状态。

SDK预览在HTTP发送前保存请求并停止，不执行推理；其错误记录不计为模型能力或未来任务结果，预览子会话不用于原生评价。实际评价额外保存请求，并核对模板token与API报告的首轮输入。每题四组初始token相同，范围1676–2675，实际差值为零。短输入使用明确标为无事实/无指令的中性零填充；当前任务放在填充之后。总调用、后续token和耗时仍按实测报告，初始预算相同不等于计算成本相同。

所有评价工作区只含当前输入及空输出，不放旧笔记或旧结果；读写权限、12次调用上限、temperature0/seed17一致，任务顺序按seed17打乱。模型不更新、候选不晋升，不使用H。条件变化包括精度、哈希算法、筛选边界及数组合并规则；撤回包括分隔符、输出字段及递归保留规则。

| 表示 | 普通迁移 | 条件变化 | 撤回 | 合计 | 工具调用 |
|---|---:|---:|---:|---:|---:|
| 无历史（预算匹配） | 1/4 | 3/4 | 3/4 | 7/12 | 73 |
| 原生续接 | 4/4 | 3/4 | 4/4 | 11/12 | 42 |
| 完整外部记录 | 4/4 | 3/4 | 4/4 | 11/12 | 42 |
| Agent笔记 | 2/4 | 3/4 | 2/4 | 7/12 | 44 |

原生与完整记录的逐题通过向量也相同。笔记相对无历史三得三失，净分相同，不能说没有任何作用。两种完整历史都在新数组追加要求下沿用旧替换方法；笔记在明确撤回ids后仍写ids。原生历史并未排除错误复用，自由提炼也不能自动成为可靠Skill。模型实际写出四份笔记，语义只作为提议，未准入训练真值。

这是单seed、四共享程序族的开发对照，不能证明统计等效、所有任务上的原生优势/无优势，或完整K0/K1及M0–M3效果。填充与角色表示都会影响模型，结论限定于本预算设计；完整记录保留原始事实，笔记信息不等价，因此其差异不能只归因于检索。下一步应依据实际失败改善条件绑定、撤回传播和提炼质量，再用未曝光任务比较。

源代码入口为coevo.context_trial。显式指定配置和两段原始工作目录，输出目录必须不存在：

```bash
PYTHONPATH=src "$COEVO_PYTHON" -m coevo.context_trial \
  --config "$COEVO_CONFIG" --cohort "$COEVO_COHORT" \
  --feedback "$COEVO_FEEDBACK" --out "$COEVO_CONTEXT_OUT"
```

私有完整产物保留在忽略的runs目录；[公开逐题摘要](../experiments/real-work-foundation/context-representation-results.json)记录初始token、来源、实际调用、逐题得失及笔记哈希，不提交原始会话、请求或笔记。预览传输两个用例、信息可恢复/预算/条件三个用例和实际48次评价已执行；CPU预览不作为真实模型运行证据。
