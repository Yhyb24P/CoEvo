# CoEvo 评估与统计协议（v0.5）

适用范围更新：本文保留此前的研究设计或推进记录用于追溯。当前研究入口为[当前研究导航](当前研究导航.md)，普通用户长期日常工作、固定 Qwen3.5-4B、完整行为 SFT 与 SRFT 的研究安排以其链接的职责文档为准；本文不重判已冻结试跑。

**研究日期：2026-10-13｜状态：正式评价设计，阈值尚待独立 D 校准并逐实验冻结｜配套：[研究方案 v0.5](agent_model_coevolution_experiment_plan_v0.5.md)**

本协议唯一规定评价对象、数据隔离、反馈曝光、效应量、统计设计、科学结论和发布判断。实验因素、模型与阶段由研究方案指定；对象的来源/授权由[数据与状态协议 v0.4](01_数据与状态协议_v0.4.md)规定。v0.4 历史结果不得按本版新门槛事后重判。当前所有 v0.5 效应阈值均为研究设计建议，**不是已通过工作站验证的数值，也不能在看到 H 后调整**。

## 1. 评价对象与独立单位

`episode` 为单次任务及其当前有效指令、工具、环境、反馈事件、行为轨迹和最终检查结果。`source_cluster_id` 为原始任务/纠错及其全部派生材料的共同归属，通常是横截面比较的**主要抽样单位**；同一来源簇内的工具调用、token、轨迹摘要、纠错续接不是独立样本。`program_family` 表示工具组合、目标结构或任务程序的抽象族；`stream_id` 表示一条有独立时间顺序的长期任务/反馈序列；`training_seed` 表示权重更新随机性，不等同于推理 seed。正式 Q3 以独立的 `stream_id` 及配对的策略分支为主要推断单位。

单个 episode 的冻结元数据沿用 v0.4：`episode_id, source_cluster_id, task_family, program_family, relation_type, difficulty_stratum, initial_state_hash, feedback_script_hash, oracle_ref, expected_capabilities, max_steps`；本版新增/要求记录：`stream_id, arrival_index, evidence_origin, teacher_assistance, exposure_refs, input_context_length, current_instruction_state_ref, experience_snapshot_ref, model_version_ref, selection_policy_ref, treatment_assignment, release_decision_ref`。字段归入已有运行记录和数据清单，不再复制独立持久化数据库。教师提供的修复和提示必须带源引用，且不通过生成新 ID 伪装成独立证据。

正式评价至少区分：**来源实例迁移**（新来源、可能同程序族），**结构迁移**（留出程序族/工具组合），**时间迁移**（学习之后前瞻到达的新任务），**条件反转/失效**（表面相似但旧经验不适用），**长上下文任务**（同证据位置/干扰梯度）。同一公开 benchmark 被反复调参后只能视为 D/V/G，不再称为独立 H。涉及真实用户交互的可学习性、隐私与来源许可不由抽样策略自动授予。

## 2. 数据划分、曝光和反馈权限

| 集合 | 可以做什么 | 不能做什么 |
|---|---|---|
| `L` 学习流 | 采集真实轨迹、允许的经验/技能库、训练候选和 replay；按先测后学记录 | 不能把同一来源派生物送进对应 H |
| `D` 开发 | 核验工具、模板、数据规则、优化器可用性；估计难度/方差/吞吐 | 不能用于最终独立确认 |
| `V` 选择 | 比较候选选择策略、学习率、算法及任务构成；选择冻结配置 | 不能报告为未经选择的独立收益 |
| `G` 发布回归 | 重复评估旧能力/授权边界，接受、拒绝或回滚版本 | 即使只返回分数/通过率也不能再次算作 H |
| `H` 封存确认 | 对冻结的研究问题、系统与多个预声明对照作最终判断 | 不供训练、检索、选样、技能抽象、参数发布或人工迭代使用 |

同一实际原始交互的摘要、改写、教师续接、对比反例、语义/程序模板变量、错误修复，均继承来源簇；在独立结构泛化中另按 `program_family` 作留出。学习流可能包含将来实际时点的任务，不能把“发生在后面”本身视为独立性；必须记录结果何时被哪一模型/检索库/训练器看过。每个模型、选择器和经验版本有输入曝光 manifest；不同组若共享候选池，所有记录要能复核一致的候选 ID、标签、可见信息和选样配额。

**H 隔离**：Q1、Q2 横截面可共享事前冻结的独立面板；Q3 为每一周期冻结 `H_cycle_t`，并在周期结束保存**可恢复的模型/状态快照**，整条试验完成后再统一评分。`H_final` 只对终点模型/经验在未见结构和后续时间任务上评分。所有 H 标签、详细轨迹及结果在做完涉及该 H 的算法/版本选择之前不可见；封存期间的 H 评估由独立执行入口处理。若研究者根据一次 H 结果修改模型或协议，该 H 在下一轮降为开发证据，下一轮需新来源的 H。

`G` 用于版本晋升是**适应性反馈**。不同策略使用同一 G 和发布门槛，但不能因共同 G 就称终点评价未受选择影响。检索库及 skill 库严格禁止包含 H 的原始或派生材料。`L/D/V/G` 内可以分析失败并修改实现，但正式确认前应冻结协议及代码 hash。

## 3. 检查器与反馈真实性

以独立于待评估 Agent 的过程读取最终工件或数据库状态，采用可复位初始环境和允许多条等价路径的最终谓词。检查器隐藏答案、测试文件、判定代码和评分密钥不能作为被评估工作区的可读文件、工具输出或模型提示。Agent 原始行为和外部安全拦截/后处理要分开计分；“代理阻止违规”不能表述成“模型从未发出违规动作”。

核验器须先通过正确/错误/部分完成/空工件/伪完成声明/越界动作/工具暂时失效的已知样本检查；存在打分漏洞时记录故障并对所有配对组统一处理，不单独给予差组重试。对正式 episode 进行事前冻结比例的盲化抽查（v0.4 建议不少于 10%），所有争议及异常高分额外复核。研究者可兼任务作者和复核者，但不能声称存在独立双人一致性；LLM-as-judge 若无法避免，须冻结其版本/提示/输出 schema，报告盲化复核、分歧和置信限制，不能用待评估模型自评作真值。

反馈分层：`execution_verified`（工具后真实结果且检查器能覆盖相关目标）、`user_intent_confirmed`（用户确认任务意图/偏好）、`teacher_assisted`（研究助手或强教师生成修复）、`heuristic`（模型反思、评分器、推断的适用条件）、`unverified`。这些标签不是单一线性的“真实性排名”：用户可定义要求却不能单独证明计算正确，单元测试能证明特定测试结果却不保证完整需求满足。使用 `heuristic` 可提出候选，不能自动把未经核验的推断当作正确监督目标。

## 4. 主要指标与计数分母

**统一成功指标**：`ETS` = 在限定时间/工具额度内满足最终状态、必要输出及授权约束的 episode 数 / 指定集合全部 episode 数。失败、拒绝、超时、abort、parser 故障、非预期空输出均保留在分母；同时报告任务目标成功率、工具正确率、解析失败和预算耗尽分布。

| 指标 | 计算单位与分母 | 研究用途和必须联报指标 |
|---|---|---|
| `ETS` | 完整有效完成的 episode / 全体 episode | Q1–Q3 主要能力终点；联报应行动覆盖率和无进展率 |
| `BTR`（可迁移收益） | 同来源/程序族分层下，候选策略与对照在未见 episode 的 ETS 风险差 | Q1/Q2；注明实例、结构或时间迁移，不把同模板换值称为结构泛化 |
| `SRR`（失效经验错误复用率） | 行为与失效/不适用经验一致且违反当前任务目标/条件的机会 / 事前标注的失效经验机会 | Q1 主要风险终点；联报仍有效经验利用率、FDeR、ETS |
| `FAR`（行为） | 失效或不适用**指令**被实际用于行为的机会 / 预标注不适用指令机会 | 与 SRR 区分，联报 `FDeR`、ETS；拒绝全部任务不能算改善 |
| `FDeR`（行为） | 有效指令在规定机会未得到满足的次数 / 预标注有效指令机会 | 联报 FAR 和应行动覆盖 |
| `PGR`（撤回后参数残留率） | 禁用被撤回外部经验、明确提供新有效条件后，W 候选仍沿用撤回行为的 episode / 专设可判定 episode | Q2；与 W0 配对，区分模型旧先验、适配后残留和外部泄漏 |
| `Δ_old(t)` | 同一个冻结旧能力面板 `ETS_old(t)−ETS_old(0)`（百分点） | Q2/Q3 遗忘；联报最差程序族下降和旧任务复测可用性 |
| `FG_t`（前瞻收益） | 周期 t 新到达任务在更新前 first-attempt 的 ETS；组间配对风险差 | Q3 实际适应；区别更新后同任务重做分数 |
| `SEL`（同池选样效应） | 相同前周期 checkpoint、同池候选、同预算训练后的独立评价风险差 | Q3 机制证据；与自动生成候选能力分开 |
| `WUR`（无效更新比例） | 回归拒绝/未带来预设净收益的训练候选数 / 实际提交的训练候选数 | Q2/Q3，按拒绝、无更新、失败分列；不是单独的能力好坏指标 |
| `LC`（总学习成本） | 每个策略/流的候选生成+核验+检索+训练+更新评估+人工劳动+运行时推理之资源合计 | 必须按 GPU-h、监督/上下文 token、工具调用、人工分钟、墙钟分别报，不把它们硬相加为无依据统一单位 |
| `L128`（长上下文） | 各输入长度/证据位置/干扰层的定位、整合、工具任务 ETS 及 p50/p95 时延 | 128K 资格与实际长任务能力分开，报告后端 usage/截断情况 |

SRR 指行为层对过时/不适用经验的错误复用，不等于 FAR 的用户指令撤回；两者分别有预标注分母。SRR 是**观察性错误指标**，若要声称具体检索项导致某次错误，须进一步固定任务和参数后进行检索开关/替换的配对干预。`PGR` 为行为性残留而非参数中特定事实的存在证明；若 W0 已犯同错，需要报告**超出 W0 的变化**，不能把先验偏差全部算成训练写入。拒答、询问、等待和不必要重复验证要计入正常任务失败或对应过程指标，不采用降低行动率使 FAR/SRR 归零的指标奖励。

结果按来源簇与事前的 `task_family/program_family × relation_type` 权重汇总；分子/分母、失败和缺失都公开。训练后评估所用记忆和参数必须以不可变快照引用，不能将原始 W0 的成功轨迹和候选 W1 的运行混在同一分母。

## 5. Q1：表示和固化策略的评价契约

**预声明两部分比较**：先在 `R0/W0` 下以强简单 `K0` 对比条件化生命周期 `K1`（I-A），再固定选定 `K*`，比较 `M1` 普通轨迹/摘要记忆、`M2` 有证据/适用条件技能、`M3` 在 M2 上增加失效管理，零记忆 `M0` 提供绝对基线（I-B）。I-B 共享 W0、当前有效指令、同一合法 L 历史和工具权限。若要纯粹测抽象，应补 `M1+condition_filter` 诊断；不把条件化技能与普通记忆的多机制差称为抽象纯效应。

I-A 主要优越性效应为 `FAR(K0)−FAR(K1)`（正值表示误沿用减少），并要求有效指令满足和 ETS/应行动覆盖不出现超过预设幅度的恶化。I-B 主要优越性效应为 `M3−M1` 的未见可复用来源 `ETS` 差，主要风险对比 `SRR(M3)−SRR(M1)` 的失效/反转机会；`FDeR` 和应行动 ETS 为约束结果。`M2−M1`、`M3−M2` 分析抽象/失效治理相对贡献，预声明但不借此补报 Q1 主效果。提议策略 `P2` 与固定规则 `P1`、随机 `PR` 使用同一合法证据池和作用/撤回核验；提取的 skill 是否被实际使用以及造成何种最终状态变化，均需有可复核轨迹。

成本比较至少提供：（1）同运行时检索/上下文 token 上限的质量对照；（2）质量与**全部**候选生成/摘要/教师/人工核验费用的 Pareto 或预算约束比较。Q1 的“更优”不得仅由单任务高分、少使用外部经验或隐藏教师开销得出。

## 6. Q2：R×W、训练与遗忘的评价契约

主 `2×2` 设计的四单元在相同独立 H episode 上配对：`A=R0W0, B=R1W0, C=R0W1, D=R1W1`。主归因比较的 `R1/W1` 来自相同的 L 中**可训练证据源池**：R1 使用其冻结的外部经验快照，W1 从同源授权候选训练并先在 V/G 冻结；在 R0/R1 下为**同一个 Adapter**。允许检索但禁止训练的用户资料另作应用分析，不以它们的额外信息归因于外部学习范式。保留同一工具/parser、采样参数、当前任务事实、最大输入与输出预算；R1 所给历史内容本身就是干预，不构成与 R0 完全相同的信息。主要效果定义：

- `Δ_W|R0 = ETS(C) − ETS(A)`：**无运行时经验检索**时的参数增量；
- `Δ_R|W0 = ETS(B) − ETS(A)`：W0 下外部经验增量；
- `Δ_W|R1 = ETS(D) − ETS(B)`：已有外部经验时的参数附加增量；
- `I_RW = ETS(D)−ETS(C)−ETS(B)+ETS(A)`：风险差尺度上的经验—参数交互。

在**可泛化的新程序族**上评估增量，并分开报告同程序族新实例、旧程序族和条件反转。若只有 R1 开启时有 W 收益，不写“参数没有作用”，应报告条件性参数收益和交互；若 I_RW=0 但 ΔW、ΔR 都为正，不写“没有协同价值”，仅不能声称超加和交互。Q2 的比较须记录 W1 使用的训练来源/权限、总监督 token、优化器 steps、可训练参数清单、实际计算与候选未晋升事件；与 `R-only` 方案的全面质量/成本比较作为应用决策，不与参数效果识别混成一件事。

用于评判“值得固化”的证据要同时考虑 `Δ_W|R0`、`Δ_W|R1`、旧能力保持、PGR/SRR/FAR、训练/推理成本。**模型从外部记忆中学到的事实可能具有错误撤回风险，不能只用无检索 ETS 提升批准发布**。不同 LoRA 配方比较使用同样的合法候选池及合理的公共基线，目标/前缀长度按预先方式分层；不能声称监督 token、总上下文 token、GPU 时间和步数自动全部相等。对有决定意义的差异追加等 GPU 时间对照，实际消耗完整记录。

## 7. Q3：共享候选池机制与真实闭环评价契约

**III-A 机制实验**：对每个周期、每条独立任务流冻结候选池与来源配额，`SF`（W0 选择）、`SU`（当期已接受模型选择）、`SR`（匹配配额的分层随机）面对相同候选 ID、标签/核验信息、工具权限、输入上限和预算。候选池如混入前周期各策略产生的数据，其比例须事前平衡并作为来源因素记录。主要选样能力需同时测（a）数据本身的外部验证质量/多样性及成本，（b）从**同一 checkpoint** 出发、等预算训练后的 `SEL`；仅观察两组终点权重不同不能将差距归因于选择器。

**III-B 政策闭环实验**：将整条 `stream_id` 作为处理单元（或同一外生流复制到隔离的策略分支，按流配对）；一条试验流内按时间到达任务，更新后运行下次任务，禁止让另一策略读取本组经验与权重。除 `SF` 与 `SU` 外，保留 **W 冻结但经验可更新** 的对照，以及根据研究问题需要的固定简单规则对照。比较主要终点为各流 `H_final` 上的结构迁移 ETS 和预先定义的 `FG_t` 加权轨迹差，同时约束旧任务/失效经验及总成本。

对长期政策的因果解释限于随机化/配对流级处理与共同预算条件下的**整套政策效果**。每条实验流及策略分支须拥有独立的状态库/版本命名空间、检索索引与可写工作区；禁止共享 `.state/rsi.sqlite` 中固定周期 ID 所代表的权威状态。各分支自行生成数据时，候选分布本身可能不同，不能把 III-B 的效应替代 III-A 的选择器效应。每周期保留模型、经验、选择器与检查器快照；停用/拒绝更新、损坏中断、恢复失败与试验退出均属于结果，不能只平均成功运行的周期。三周期×两流仅是工程试点，不能作为稳健多周期科学结论。

正式统计前先在 D 建立有改善空间的真实任务、可靠检查器与难度分布。当前合成旧/新面板各 3/3 只支持工程路径，不能用于校准正向收益。T01/T04 的能力有效性与训练基线确认先于 H 规模冻结；任务进度由[任务路线](07_项目现状与任务路线_2026-10-13.md)维护，不能用代码完成量替代科学对照。

## 8. 统计分析、样本量与多重比较

**先定义 estimand，再确定样本数。** 横截面主要 estimand 为冻结任务族权重下的来源簇平均 ETS 风险差（绝对百分点）；Q3 主要 estimand 为独立任务流/配对流在冻结累计资源条件下的终点/前瞻表现差。涉及 3 个训练种子时，种子与来源是交叉变化因素；推理多次采样不等于多个独立训练重复。交互项使用四单元在**同一重采样**中计算。

样本量由 D 中得到的任务基线、配对不一致率、簇内相关、程序族分层、长时程/流间方差和资源成本确定。v0.4 中的 `36 来源簇×2 episode` 用于试点，`120–480 来源簇/主要比较` 是未经本版校准的初始设计区间；不得将其写成当前已达到或正式样本量。正式 H 前模拟功效/置信区间宽度，冻结所需独立来源簇及独立流数量；若预算不足，报告估计精度限制而非硬称无效。Q3 不因周期数增加而提高独立 `stream_id` 样本数，少于足够独立流的结果仅报轨迹和探索性区间。

分析采用分层来源簇 bootstrap 或与设计匹配的层级模型；含训练随机性时保持 `source_cluster × training_seed` 的交叉结构并分别展示各种子；Q3 在 `stream_id`/成对流层做重采样，保留流内序列相关。默认至少 5000 次 bootstrap，报告 95% 区间、原始计数、各程序族与最差族、失败/退出数量，并对个别种子/任务流做敏感性检查。若仅 2 条流，不输出误导性狭窄“长期显著性”区间。

**主确认家族与多重性**：按三个科学问题预设四项主要优越性 estimand：I-A 的 `FAR(K0)−FAR(K1)`、I-B 的 `M3−M1` 可迁移 ETS、Q2 的 `C−A` 无检索结构迁移 ETS、Q3 的 `SU−SF` 在 III-A 同池交叉重训后的独立终点评价差；四项共同纳入 Holm family-wise α=0.05；Q3 III-B 的完整政策增量作为第二阶段独立确认，实施前单独预注册推断家族。I-A 的 FDeR/ETS、I-B 的 SRR/有效行动覆盖、Q2 的旧能力/PGR 是**联合守门条件**，须满足事前非劣/风险标准；不能因主要 ETS 显著而忽略风险。其他 R×W 交互、M2/M3 增量、算法变体、128K 分层属于预注册次要或探索性结果，报告区间及必要的多重性限制。不同任务分布不能因有利结果挑选进主分析。

**暂定实用阈值，必须在独立 D 校准后、H 前冻结：**（i）主要 ETS 进步参考 5 个百分点；（ii）旧能力 ETS、有效指令遗漏及应行动覆盖的允许恶化参考 3 个百分点；（iii）指令 FAR 改善的参考实际量级为 3 个百分点；对失效经验误用，优先要求方向明确且未造成上述正常任务损失，若 D 显示基线风险极低，按真实使用风险修改门槛而不是人为制造失效事件。非劣采用预注册的单侧 97.5% 置信下界与阈值比较；“差异不显著”不是非劣证据。对于零违规，报独立簇级的单侧风险上界而非宣称概率为零。正式证据不足时使用“不确定/精度不足”；仅当区间足够窄且排除事前有实际意义的收益，才写“未发现值得投入的增量”或适当的等效结论。

## 9. 128K+ 资格与长任务评价

“可填入 131072 token”与“能完成长任务”是两类指标。实际资格以 tokenizer/chat template 与后端 `usage.prompt_tokens` 联合校验，并查是否无声截断/压缩；留下生成/续接空间。长任务面板覆盖 32K/64K/128K、多位置证据、分散信息整合、过时干扰、工具返回增长与多轮状态；至少报告每层实际输入长度、正确定位、正确授权行动、整任务 ETS、工具错误、耗时与显存。学习前后使用同题型的**不同来源**配对而非训练里用过的 needle。若长窗口优于 RAG 却利用了额外有效证据，只报告相应系统差，不将其解释为“长上下文固有更优”。笔记本量化与后端测试在最终阶段 D 独立报告。

## 10. 科学确认、版本发布与失败处理

正式研究结论的证据层级：**已执行并核验的源/状态 → D/V/G 机制与选择分析 → H 独立确认 → 独立流复现/部署外推**。只有工程链路真实运行不能称能力提升；某方法只在 V/G 有增益不能称 H 证实；共享池实验有选择器收益不能称开放闭环已证明；三个周期运行成功不能称长期收敛或自进化成功。

发布使用 G 与实际授权风险门槛，不能等待 H 对每个候选进行“发行筛选”；对确定性权限越界或来源/训练授权失效设置事前不可放宽的发布阻断条件。研究结果允许继续保留失败候选用于分析，拒绝晋升并不抹掉负结果。一次训练超时、权重更新失败、工具解析错误、意外缺失数据、模型中止或流退出须进入对应分母与成本；只能针对确证的组间共同基础设施故障统一重跑整个配对块，并保留原记录。所有事故、阈值修订及 H 解封时点在实验清单中留痕。

**每项正式实验的冻结单应包含**：研究问题与主要估计目标、组与任务抽样、源簇/程序族/流归属、输入/反馈曝光表、状态/权重/选择器快照 hash、检验器版本与有效标签、监督 mask、随机化单元/种子、运行与训练预算、主要与风险终点、阈值与多重比较计划、独立 H 管理、预定失败与缺失处理、版本发布规则。字段继承 [实验记录模板 v0.4](05_实验记录模板_v0.4.md)，本版新增项由扩展 manifest 记录，不建立冗余并行格式。
