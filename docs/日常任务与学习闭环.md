# 日常任务与学习闭环

本文件描述首批**拟研究**的普通用户任务，不是仓库已实现功能的声明。复杂科研和大型软件工程不要求 Qwen3.5-4B 独立完成。

| 程序族 | 日常任务 | 应学习的行为 |
|---|---|---|
| 文件 | 查找、归档、重命名、重复文件处理建议 | 规则适用条件、目录许可、用户修改 |
| 文档与笔记 | 局部修改、格式整理、信息摘录 | 临时要求与长期习惯冲突 |
| 表格 | 列名归一、筛选、汇总、模板转换 | 缺字段、歧义、校验结果 |
| 信息和清单 | 指定资料提要、待办维护、更新记录 | 时间有效性、已完成/撤回事项 |
| 有界本地工具 | 按许可操作、出错后纠错或停止 | 正确工具、授权和执行能力边界 |

在重复但不同来源的任务中观察经验迁移，设置有效、无关及条件反转的任务；成对覆盖可执行、缺信息、缺权限、工具不可用、模型不能完成的情况。用户无需重复解释时是否确实减少纠错，是产品层的重要终点；是否由参数或记忆造成改善，需要 Q1–Q3 对照。

交互学习流程：保存**当前授权**的有效指令和任务状态 → Qwen3.5-4B 执行、询问或有据停止 → 工具结果与用户纠错 → 来源/权限/正确性确认 → 不学习、保存实例、形成有条件 Skill、列入参数训练候选或撤回 → 已授权的完整正确行为 SFT 与 SRFT → 旧能力/新任务评价、接受或回滚 → 下一次真实任务。

私人交互的执行许可不代表训练许可；账户权限、用户偏好、文件路径和动态事实必须能够在外部状态撤回。模型可提出技能或选样建议，但不能仅靠自己的反思认定正确。外部学习和参数学习可以并行，不要求记忆先饱和。邮箱、日历和网站若尚未真实连接且授权，不作为已能操作的服务。
