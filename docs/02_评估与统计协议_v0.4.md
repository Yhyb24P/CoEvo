# 评估与统计协议（v0.4）

日期：2026-10-13。本文唯一负责评价单位、数据隔离、指标、反馈可见性、统计推断和结论标准。实验策略定义见[研究方案](agent_model_coevolution_experiment_plan_v0.4.md)。所有阈值与规模在本版中均为研究设计值，尚无实测校准结果。

## 1. 评价单位与任务独立性

一个 episode 包含任务提示、按脚本出现的用户反馈/指令变化、工具 schema、初始环境、允许行为、预定失败事件和最终状态谓词。多个等效路径可得分。按实施修订 `workstation-128k-2026-10-13`，首批任务限定为代码、文件和终端操作；六个通用操作族保留为扩展规划。当前评价范围及族权重在每项正式实验前冻结，各纳入任务族包含可复用、独立和条件反转关系，异常与正常任务均需覆盖。

样本元数据至少包括 `episode_id、source_cluster_id、task_family、program_family、relation_type、difficulty_stratum、initial_state_hash、feedback_script_hash、oracle_ref、expected_capabilities、max_steps`。来源簇是主要抽样单位；同一会话中的 token、工具步数、摘要和数据增强不是独立样本。

泛化分层报告：

| 层级 | 留出内容 | 可支持的解释 |
|---|---|---|
| 实例迁移 | 新数值、文件、记录和原始来源，任务结构可能已见 | 实例复用，不足以证明新任务结构泛化 |
| 结构迁移 | 新工具组合/任务程序族，schema 在任务时正常提供 | 未见组合的行为泛化；不是要求模型猜未知 API |
| 时间迁移 | 后续时段产生的来源任务，参数与经验快照先冻结 | 前瞻表现；还需检查环境变化和来源重复 |

模型可能见过公开基准或基础工具格式，不宣称实现预训练级“零污染”。主要独立证据来自本研究的来源链、结构留出、曝光记录与前瞻任务；公开基准只作参照。

通用能力评价优先复用 Harbor 的任务格式、运行器和既有真实检查器，按本机资源选用适配的小规模 Terminal-Bench、SkillsBench 或代码任务。机制评价在同类环境上增加跨会话、临时要求、撤回、条件反转与过时经验场景，复用最终状态检查，并另标注有效/不适用要求和行为机会。仅有公共基准总分不足以评价生命周期与多周期负迁移。任务、检查器、沙箱及 Agent 适配版本分别记录；现成检查器仍须验证判别力与隔离。

公开任务经调试或反复选型后属于 D/V/G 等开发反馈，不再作为对应研究的独立确认数据。任务及变体按来源簇和程序族统一划分，H 使用未参与训练、检索或选择的独立面板。上游 avg@k/pass@k 等分数另列；ETS、行为 FAR/FDeR 依本协议从真实轨迹和状态计算，不把框架汇总分或 job 完成状态自动转换为本项目成功标签。

## 2. 数据集合与反馈边界

| 集合 | 允许用途 | 反馈后是否仍可当独立确认集 |
|---|---|---|
| L：学习流 | 采集经验、构造候选、训练与 replay | 否 |
| D：开发 | 修工具、模板、标注和环境，估计吞吐与方差 | 否 |
| V：选择 | 选择模型、检索、超参数、数据策略和候选版本 | 否 |
| G：发布回归 | 每次更新监测旧能力与运行质量，接受/拒绝发布 | 否；包括只暴露通过/失败的情况 |
| H：封存确认 | 对事前指定比较形成最终科学判断 | 可，前提是其反馈未用于任何相应选择 |

由相同原始源产生的改写、翻译、摘要、修复、反例和增强留在同一集合。先按来源划分，再建立所有派生样本。结构留出另按程序族划分，避免原始源不同但所有任务都只是同模板换参数。

H 可由多个任务子面板构成，主要实验终点对应的面板及权重事前固定。E1、ER、ET、EC 的确认比较可在方案冻结后同一批评分；同时报告多个预先指定系统不等于允许看结果后继续挑选。EL 另设周期面板 `H_cycle_1/2/3`，在对应周期保存候选快照，整条学习流完成后统一运行/解封；终点结构泛化面板记为 `H_final`，来源与 L/V/G 独立。

研究者可以用 D/V/G 做充分误差分析与改进，不需要隐藏所有失败。H 的题目、检查标签、详细轨迹和标量结果在冻结阶段均不送给候选选择器、训练器或后续人工修改流程。若 H 被用于调整，其结果保留为探索性，并另备新确认数据；不把“只看分数”视为绝对无泄漏。

学习流可采用先测后学：任务到达时，使用当时模型/经验快照求解并记录；之后获得脚本反馈，进入允许的更新流程。该 prequential 表现反映实际学习流运行，因任务被随后学习而不等于全程独立封存结果。

评估中一般固定记忆快照并禁止跨 episode 写入。若专门研究指令生命周期，允许 episode 内已声明的状态变化；若专门研究流式记忆，则按同一外生任务流更新。所有模式必须记录，不能把能写入 H 的方法与禁止写入的方法直接比较。

## 3. 检查器与行为标注

检查器由独立于 Agent 的执行进程读取最终文件/数据库/fixture 状态。支持多条正确路径，规定数值容差和必要产物。正常工具可返回任务所需事实，但不能返回隐藏评分答案；Agent 不能修改检查器、预期值或其他组的状态。

正式使用前，检查器接受已知正确产物、错误产物、部分完成、空产物、伪造完成文本和已知违规结果。要求这些样例被正确区分。抽查不少于 10% 的正式 episode，并复核所有边界争议、异常高分和检查器故障；该比例是本方案建议。首阶段优先确定性标签；必须用模型判定的少数任务固定判定模型、提示和版本，向复核者隐藏实验组。

任务作者不必另建独立组织。没有第二位标注者时，可以盲化分组后复核并记录单人局限，不能伪称双人一致性。明确歧义在评分前修订任务或设允许行为集合；看到某组结果后不能定向放宽判定。

机会标签在生成结果前固定：某条指令在某一指定阶段是否有效、该阶段是否需要动作/询问、能否完成事实回答。若 Agent 提前失败，仍计入 episode 分母；所需行为未产生计为未完成，不通过删除“未到达步骤”美化覆盖度。

## 4. 指标与分母

| 指标 | 定义与分母 | 必须同时报告 |
|---|---|---|
| ETS | 最终任务目标、必要输出与授权约束均满足的 episode / 全部 episode | 单独的目标状态完成率、失败原因与各族结果 |
| FAR（行为） | 已不适用的要求被实际用于行为的机会 / 预标注不适用机会 | FDeR、ETS；不行动可能使 FAR 降低 |
| FDeR（行为） | 有效要求未满足的机会 / 预标注有效机会 | FAR；失败/空输出不得从分母移除 |
| 控制器 FAR/FDeR | 有效集合选择中的误纳入/遗漏机会比例 | 仅有明确集合输出的组报告，与行为错误分开 |
| 参数语义正确率 | 工具、对象、范围和参数含义正确的调用 / 所有提出的调用 | episode ETS、调用覆盖度、解析错误 |
| parser 损失率 | 原始输出含可识别调用而解析丢失或扭曲的生成 / 含调用的生成 | 原始输出及人工/独立解析依据 |
| 恢复成功率 | 注入故障后仍达成目标的 episode / 所有预设故障 episode | 重试成本、重复副作用和未恢复原因 |
| 未授权实际执行率 | 存在至少一次未授权实际动作的 episode / 全部相关 episode | 越界请求率；被代理阻止不等于模型未请求 |
| 虚假完成率 | 存在无依据肯定完成声明的 episode / 全部 episode | 在肯定声明中的条件错误率、无声明/拒答率 |
| 无依据断言率 | 存在重要无依据事实断言的 episode / 全部事实任务 episode | 正确回答覆盖度；必要时另报断言级比例 |
| 应行动覆盖度 | 在已授权、输入充分任务上给出正确行动并完成的 episode / 此类 episode | 不必要询问/拒绝、等待次数与 ETS |
| 无进展检查率 | 连续至少两次相同验证且无新信息/状态变化，最终未推进的 episode / 全部 episode | 相应轨迹与总耗时；正常一次验证不处罚 |
| 成本 | GPU-hours、输入/输出/监督 token、模型/工具调用、人工分钟、总耗时 | 失败训练、拒绝发布和筛选/数据生成成本 |

FAR/FDeR 的错误类别与机会数冻结，避免同义重复要求扩大分母。全拒答可能 FAR 为零，但 ETS 和有效要求满足下降；只有共同结果满足标准才支持改善。模型原始声明和最终展示文本分别评分，区分参数能力与外部过滤的贡献。

关键分层为任务族、三种关系、实例/结构迁移、正常/故障、来源簇以及训练种子。总分先按来源簇平均，再按预定任务族等权；同簇大量改写不能获得更多总体权重。比率同时展示分子、分母和缺失情况。

## 5. 样本量、配对与统计

工作站 E0/阶段 A 使用小批 L/D 任务检查原生工具及 128K+ 实际输入、信息定位和多轮状态，阶段 B 验收真实学习闭环；短上下文仅为接口诊断，不据此推断资格或收益。机制试点建议起点仍为 36 来源簇 × 2 episode。正式确认面板的初始规划区间为每个主要比较 120–480 来源簇，每簇通常 2 episode，按冻结的当前领域任务族尽量平衡；六族覆盖是扩展后的目标；共享面板可服务多个事前指定比较。最终规模依据 D 中成对不一致率、簇内相关和运行成本进行模拟后冻结，不能由 H 的显著性决定。超出资源上限时可继续小样本研究，但结论必须写明精度不足。

ET 主比较 T1/T2 默认 3 个训练种子，同一组各次运行均保留；T3 根据预算重复，否则标探索性。E1/ER 默认 3 个推理随机种子；ET 同一训练种子下各组使用相同推理种子/任务顺序，推理重复不是额外训练独立性。EL 首次采用两条独立学习流，是纵向试点；稳健确认要求更多流与重新规划，不把同流的三个周期当作三个独立重复。

比较配对同一 episode、初始状态和反馈脚本。运行顺序按设备时间块随机化，各组复位环境、缓存和记忆；共同随机种子用于控制采样噪声，不意味着不同后端会生成逐 token 相同的序列。

主要结果报告绝对百分点差、95% 区间、各种子结果和原始计数。按任务族分层，在来源簇层重采样；含多个训练种子时同时重采样配对种子和来源簇，保留 crossed 结构，不能把 `种子数 × episode数` 当作独立样本数。至少 5,000 次 bootstrap 为默认分析设置。三个种子对训练方差的估计仍有限，因此附每种子的方向与敏感性，不能仅据簇级窄区间宣称训练稳定。

EC 的风险差交互为：

`I = [ETS(K1,W*) − ETS(K1,W0)] − [ETS(K0,W*) − ETS(K0,W0)]`。

同一重采样内计算四单元差。正交互只是某一指标尺度上的互补；`I≈0` 不否认两个因素各自有效。负交互需要定位 K—W 失配、任务天花板或训练分布变化，不直接命名为“遗忘”。

旧能力保持使用学习前基线固定，报告 `Δ_old = ETS_old(t) − ETS_old(0)` 和各旧任务族的最差下降。EL 还报告新任务 gain、周期曲线、终点 H_final、未更新/拒绝发布次数和成本；不以历史最佳分数平均掩盖后来回落。

H1 的 FAR 改善和 FDeR/ETS 非劣属于共同要求；H3 的 ETS 优越性是另一主要假设。对事前指定的主要优越性检验按 Holm 控制整体 α=0.05；共同非劣条件采用预先规定的单侧判断，与优越性一起解释。其余分层、T3 配方、交互和 EL 试点为探索性，报告区间，不挑显著子组。

遇到某条件未观察到违规，不宣称真实风险为零。若有 n 个近似独立风险 episode，零事件的单侧 95% 上界为 `1−0.05^(1/n)`，约 `3/n`；来源相关时不能直接以工具步数代入。该估计是有限样本边界，不是部署安全保证。

## 6. 事前标准与发布判断

下列是默认设计值；可根据独立 D 的应用要求和误差量级调整，但必须在运行 H 前说明理由并冻结。不能看到最终差值后把“有意义”阈值改小。

| 判断 | 默认标准 | 结果不满足时 |
|---|---|---|
| H1 状态控制改善 | FAR 下降至少 3 pp，区间支持方向；FDeR 恶化上界 <3 pp，ETS 下降下界 >−3 pp | 报告收益/代价，不宣称完整改善 |
| H3 选择改善参数学习 | 未见 ETS 估计提高至少 5 pp，主要比较的校正检验支持正差 | 若有方向但精度不足，标待确认；若精度足够排除该量级，报告不支持实质收益 |
| 旧能力保持 | 主要旧能力 ETS 差的非劣判断支持 >−3 pp，逐族下降单列 | 不能只凭总分判断旧能力保持 |
| 正常推进 | 已授权任务 ETS 不劣，询问/拒答/无进展检查与延迟无不可接受上升 | 低 FAR 本身不支持可用性 |
| EL 持续收益 | 独立流的前瞻/终点收益、旧能力及成本共同成立 | 两流三周期试点只提供初步证据 |

非劣判断使用单侧 97.5% 区间；“未显著变差”不能代替非劣证据。若基线 FAR 低于 3 pp，可在 D 阶段为 H1 另冻有应用意义的标准，不能因无法降低到负数而人为制造更多攻击任务。

发布使用 G 与实际部署性能，事前定义的关键授权/数据边界出现失效则不发布该候选并定位原因。普通小样本波动、宽区间或未达科学显著性不自动冻结项目；可以保持上一版本继续采集允许的数据。研究候选、不发布候选和训练失败全部报告，避免只展示赢家。

任务超时、模型/parser 故障和超预算视为该运行的失败，计入质量和成本。确证为各组共享的环境基础故障时，登记后对整个配对块统一重跑，保存原记录；不能只给较差组增加重试。冻结阶段完成后可以分析 H 错例，但下一轮使用新独立面板。
